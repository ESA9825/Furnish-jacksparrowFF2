# 讲解与成果导出

## 讲解内容与采图

1. `get_presentation` 读取完整可编辑文字、稳定页 ID、事项、sourceKey、采图和版本状态；需要配置时先保留无关页与事项。
2. `configure_presentation` 提交完整 presentation。pages 的 capture 省略保留同 ID 原图，null 才删除；不注入外部图片或伪造版本记录。新页 ID 生成后保持稳定。复杂配置先读仓库 `docs/PRESENTATION.md`。
3. 设计意图、取舍与人工结论须有用户要求或明确依据；建议与已确认结论分开。人工确认使用读取的当前 sourceKey，不将自动空间检查结果写成人工确认，不替用户消除待确认项。
4. 采图前先设当前生产视角，实际看图后用 capturePageId 采集指定页。布局、材料、采购或价格改变后检查过期状态，按需重采；旧图保留不代表当前有效。讲解图是快速生产模型示意，不宣称为 Cycles 渲染。
5. 内容与有效图片核对后，按用户需要用 releaseLabel 记录版本。版本标签不冻结方案，亦非审批凭证；需要保留当次快照时实际导出。记录版本不会自动确认事项或更新旧图。

## 文件导出

`export_artifact` 使用当前 planId/revision 和唯一 requestId，在固定 `.local/mcp-exports/` 生成文件；检查返回的路径、字节数与 SHA256，不猜文件名，不要求任意目标路径。

| format | 适用交付与前置条件 |
| --- | --- |
| project | 完整可编辑项目，包含当前户型的布置、方案／历史及家具库；不只是当前单个家具清单 |
| quote_csv | 原报价行；区分参考价、确认价和费用依据，未知价不当0元已确认 |
| plan_svg / plan_png | 先 set_camera 到2D；沿原二维成果清理编辑叠层 |
| report_html | 离线成果，包含有效已采讲解图与可编辑项目；不会自动采新三维图，也不要求当前为3D |
| scene_glb | 先切到3D，待实际生产几何及活动部件稳定；按要求选择 includeCeilings；导出不是渲染 |

导出发生 revision 变化时重读，确认目标状态后再操作。文件回执不等于正式方案 persisted；仍按主技能单独核实方案保存。take_screenshot 返回原生 MCP 图片，不是自动写出的磁盘文件；成果图与含选中叠层的窗口截图用途不同。

需要调整交付阅读对象或特殊格式而当前 schema 不支持时，明确范围并使用已有界面能力，不杜撰 export_artifact 参数或擅自改底层方案文件。最终链接使用实际返回的绝对路径；说明仍待确认的资料、空间或现场要求。
