# 90° L 形转角柜：工艺调研与组件决策

2026-11-17。对象是 1601 厨房 B 的转角柜腔与两片折叠门。本文是研究结论与实现边界，不是已发布组件、五金选型单或加工图；调研阶段未修改正式方案或应用代码；后续经用户批准实施的参数组件与1601迁移另见 [组件说明](CABINET-CORNER90.md)。

## 决策

先定义「90° L 形柜腔」的独立参数化构造，再组合板件连接工艺、开门五金与内部收纳。第一阶段目标为普通层板加折叠门；不把现有三块 L 形 profile 和 135°／60°演示路径直接包装成厂家通用模板。

需要修正此前判断：连续柜腔不等于所有板件必须一整块。分段板、柜段连接及合理的接缝可以是正规结构；原方案的问题在于连接、承托和空间关系没有完整表达，不能据此把「无任何接缝」当成制造标准。

## 工艺应如何表达

1. **柜腔与板件切分分开。** 先闭合外轮廓和开口，再选一体或分段板。分段时明确接合面、连接件、承托及重复板取消规则；没有接合构造的零碎补条不能自动算成有效支撑。
2. **顶、底、层板不是同一种配置。** 顶部可选横撑／完整板／局部承托；中层可选固定、活动或分段。具体选项适用范围需由结构或制造配置限定。当前一整块 L 形顶板与固定中层只保留为 1601 的布局变体。
3. **地脚跟随受力位置与接头。** Wren案例的数量不推广为默认值；同样不能把原来两柜的脚数简单相加就宣称承重通过。石材台面支承、靠墙固定、开孔与检修应独立表达。
4. **门铰先选配置，再推门片。** 闭合夹角、柜身铰链标称角和门间铰链标称角是不同输入。标称角还须按该安装图的坐标约定换算；门厚、盖量、门缝、底座高度、杯孔位置及铰链凸出占用共同决定可行性。
5. **操作路径不等于机械传动。** 所查资料未证明这类普通双铰链门按固定比例自动同步。现有 `fold-first` 和 `foldShare=.25` 是软件演示路径。未绑定真实连杆／凸轮机构时，应保留两轴状态与选定操作路径，不把这一条路径的检查宣传为全部可达姿态验证。
6. **制造和安装留有边界。** 板件封边、内角加工、运输拆装、装配顺序及层板可取出性须能记录，未知值不编造；内角圆角、连接件数量和螺钉规格不从营销效果图推断。

## 参数化组成：研究阶段定义（实施状态见组件说明）

| 层级 | 主要输入 | 必须派生或校验的结果 |
| --- | --- | --- |
| 柜腔几何 | 两边外长、两边柜深、自身高度、底部离地、转角方向 | 实际L形轮廓、两个正面、净开口与装配尺寸链；允许两边深度不等 |
| 板件构造 | 板厚／背厚、包板关系、一体或分段、接合位置、顶撑、层板和踢脚 | 实际板件及稳定身份、接头／支撑、开口连续性；不重复生成侧板 |
| 门与五金 | 主铰侧、两门尺寸或受约束分配、盖法、门缝、产品与安装变体 | 门宽闭合、安装孔区、底座及铰杯、硬件实体／占用；不允许自由改宽后悄悄破坏尺寸链 |
| 开合与核对 | 两轴状态、操作路径、限位来源 | 选定路径的起步／途中／全开扫掠；相邻抽屉、把手、墙、板件和硬件冲突 |
| 安装／检修 | 完成面、调节脚、管线、设备开口、拆装件 | 高度只叠加一次；检修净口、部件取出与未知安装信息 |

几何可采用外墙角为基准的两矩形并集：`[0,A]×[0,dA] ∪ [0,dB]×[0,B]`。两段前沿的几何长度为 `A-dB`、`B-dA`；这是设计几何推导，不是最终门板下料公式。板厚、包板、盖量与选定五金还需继续扣算。不得再让用户通过三个 profile 的顶点独立维护同一个转角。

## 对 Furnish 的实现约束

- 先支持一个拥有实际共享板件的转角柜对象，由核心生成轮廓、板件和净空；不是两个仍相互独立的矩形箱再外接跨箱板。L形凹口必须进入生产模型、2D、测距、碰撞、吸附及正视图。
- `board.profile` 可作为旧实例和加工覆盖的兼容表达，但新模板以转角参数为源；不能同时保存两份可相互矛盾的尺寸真值。
- 规则与适用范围放 `product-rules` 和共用柜体核心；UI继续草稿／`mutate`。新持久字段需明确格式门槛及导入、复制、替换、撤销、恢复、命名方案、缓存／确认失效。
- 默认顶面生成须读取真实L形承托轮廓，不能用其矩形外包填平凹口；共享层板不能在另一个局部柜箱的正视和净高标注中消失。
- 五金分为「通用布局演示」「已绑定产品／安装变体」两种证据状态。后者也不能仅凭通用门板扫掠就宣称厂家承重或安装合规。
- 验收包括等深／不等深、左右转角、旋转镜像、离地、最小开口边界、实际构造／净口、行程与硬件、全案及项目恢复。板件连续与拆装工艺分别判定。

## 1601 的具体决定与未决项

采用「不等深90°连续柜腔＋普通层板＋双片折叠门」作为后续组件目标，先不选专用旋转拉篮。现方案400／225深、298／178门宽、18板厚、710门高、135°／60°路径均为既有布局值。搜得的标准成品案例不能证明这一不对称配置已适配；本轮未找到能直接确认178窄门及当前安装组合的厂家整套配置。

实施前仍需：选定柜身铰链与门间铰链的确切型号／安装变体；按当前不等宽门验证杯孔、底座、把手及重量；确定连接工艺、石材承托与是否需活动层板。无法核实的项维持未知，不能用软件初值代替。

因此，本轮结论是保留当前方案作外观／空间原型，将真实柜腔参数、生产切分和五金配置解耦后再实现通用组件。不会仅将现有特例存成一个预设，就标为参数化转角柜。
