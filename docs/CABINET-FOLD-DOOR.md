# L 形柜门双轴联动

2026-11-17。组件柜新增 `foldDoor`，普通柜、厨房原模块和内嵌独立柜箱共用。它表达两片刚性门板的双轴布局路径，不模拟某一厂家的铰链连杆、偏心铰轴、螺钉或受力。已有门组保持原数据和行为。

## 参数与安装基准

规则集中在 `product-rules.cabinetBuilder.foldDoor`。所有长度为 mm，角度为度。组件按柜箱定位，箱体与整套家具的安装离地只沿原核心叠加一次。

| 字段 | 语义 |
| --- | --- |
| `bay` | 组件所属隔间，供选择、复用和编辑，不虚构额外隔板 |
| `x/z` | 主轴相对当前柜箱中心的左右／前后位置；前为局部 +Z |
| `bottom/height` | 门底距柜箱底、门片自身实体高，分别编辑 |
| `primaryWidth/secondaryWidth` | 两片实体宽，60–1200；板厚随柜箱 |
| `side` | 主片沿局部右／左伸出，整体镜像仍沿原家具变换 |
| `jointGap/edgeGap` | 副片相对主片末端的轴向接缝／前向偏移，0–30；为布局参数 |
| `maxAngle/foldAngle` | 主轴／副轴全开限位，分别为 1–180°、0–120° |
| `sequence/foldShare` | `fold-first` 先折副片再转主轴；`simultaneous` 两轴按进度同步，供比较。先折阶段占比 .05–.95 |
| `open/progress` | 整组开关、0–1 开启进度；关门只改变当前姿态，不缩小核对行程 |
| `color` | 可选门面颜色；不清空间确认 |

组件库默认 300／180 宽、主轴 135°、副轴 60°、先折比例 .25 是软件布局初值，不是厂家安装或限位要求。新建不改旧实例；复制和组件复用保留结构，复用规格关闭门组，替换家具沿原产品规则清理柜体。

两片板的姿态由 `cabinet-builder-core.foldPose/foldParts` 派生。第二片先绕主片末端副轴，再随主轴整体旋转。几何以同源棱柱进入二维、三维、当前实体、测距、缓存和 GLB；不拉伸门片，也不在运行网格上临时摆姿势。点击任一片开关整组，搭建器可编辑进度、路径和两个限位；沿原草稿、`mutate`、撤销及正式保存。

## 完整行程检查

`foldZones` 独立于当前开合进度，按两个阶段显式分段。每段最多 1°角变化，并按尺寸自适应细分，使两旋转半径的弦误差上界不超过 .02mm；使用相邻姿态凸包并按该上界扩张，避免仅检查离散点或总包络。新联动门判定采用 .05mm 计算接触容差，避免沿用普通平面核对的5mm容差漏掉小干涉；这是算法容差，不是施工门缝。保留每片、每段的高度及行程比例，厨房和柜体沿原 `placeOpening/shiftOpening` 统一旋转、镜像与标高。

联动门检查同一宿主里的其他真实生产板件，仅排除所属这组联动门自身两片。报告起步、途中、全开限位区间的命中。对本柜抽屉另比较完整行程，提示需错开使用；扫掠重叠表示存在相互占用的组合，不声称两个全开端态必然相撞。外部障碍继续检查已知／未知高度、墙、管线、梁和吊顶。联动门板不自动切管孔，管线命中按未开孔门片的完整扫掠报告。

边界：双轴路径是可调的布局假设，不证明实际铰链可以按给定比例运动。小于保守弦误差的余量需结合真实五金复核。未新增抓手、铰杯几何、受力和防下垂验算；相邻普通柜门仍沿原规则，不扩展为任意多活动部件同步求解。

## 持久化与验证

含新组件最低 v92；当前、命名方案、组件库、项目、正式仓库和本机缓存接受 v92。旧实例不补写字段，原格式版本按所含字段继续派生；显式结构和两轴限位进入核对指纹，配色、采购信息不清空间确认。

- `node tests/test-cabinet-fold-door.cjs`：72 组三维生产姿态与数值实体、刚性尺寸、旋转／镜像／安装高度、完整扫掠包含中间姿态、同宿主障碍与抽屉交互、接触边界与0.2mm穿入、未知高度、严格输入、项目及连续恢复、命名／库／仓库／缓存。
- `scripts/verify/verify-cabinet-fold-door.browser.js`：隔离 HTTP 与断网 `file://`，真实编辑、撤销重做、场景开关、项目往返、刷新、390px、三维 GLB 回读中两片稳定生产身份与有效几何。
- 原组件搭建、多段门、开放区、编辑、三维开启、厨房、异形台面、工作区缓存、仓库版本和项目相关增量回归通过。原柜体 UI 在 HTTP／file／隔离 Electron 通过。未运行全量检查。

## 1601 副本的落地参数与反例

用户指定副本沿同一厨房宿主使用 298／178 实体宽、710 高、18 板厚；主轴相对新柜箱 `(253,200)`、门底 101，主轴 135°、副轴 60°、先折比例 .25。数值依据既有方案与本次布局验证，不是现场复尺或五金图。

原浅柜层板前沿退让 18，避免穿入窄门闭合带；在内侧补 18 宽桥接板，保持转角层板连通。踢脚增加 41 长收口段连接原踢脚，未改变调节脚位置。两片门面沿原厨房配色。

在正式生产构造的隔离快照中：

1. 当前先折后开完整行程未报本柜板件干涉；闭合与全开检查结论一致。
2. 切换为同步开启，可检出起步段与灶下抽屉板相交。
3. 主轴限位增至 155°，可检出途中与相邻柜门及全开附近板件相交。
4. 拉出灶下抽屉，可检出中途实体冲突；常态保留两者完整行程重叠、需错开使用的提示。

正式窗口查看闭合、副门折叠、全开三姿态并取得保存回执；正式工作区 v92 回读通过。备份对比显示其他命名方案未改变、当前只有厨房宿主变更。私人方案与截图留在本机交付目录，不提交入仓库。原方案已有管线、墙体及房间边界提示保留。
