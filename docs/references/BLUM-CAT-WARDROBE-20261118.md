# 猫道上柜铰链参考

2026-11-18，针对1601主卧本轮设计读取 Blum 官方《Catalogue and technical manual 2024–2025》。以下页码以页面正文印刷页码为准，网站标题页码有偏移。链接为厂家原文；没有将经销商信息当作厂家要求。

| 官方资料 | 本轮采用的信息 | 本案处理 |
|---|---|---|
| [76页：110°标准铰链](https://publications.blum.com/2024/catalogue/en/76/) | CLIP top BLUMOTION 有全盖、半盖及内嵌等应用；列出71B3550等型号和70T3553的86°限位件。 | 先确定门板盖法和周边干涉，再选具体组合；软件90°不是已选购五金的承诺。 |
| [77页：规划与门缝](https://publications.blum.com/2024/catalogue/en/77/) | 杯孔边距、门厚、底座间距和盖量共同影响门缝及开启突出量。 | 不能仅凭“18mm板”直接套用某个孔位或认定不会碰帘。 |
| [152页：十字底座37/32](https://publications.blum.com/2024/catalogue/en/152/) | 官方列出37/32底座系列、固定方式及其适用附加螺钉条件。 | 侧板前段保留完整实板供底座固定；选定型号后再做孔位图。 |
| [123页：铰链数量](https://publications.blum.com/2024/catalogue/en/123/) | 数量与门重、门高相关；建议增大铰链间距；所示载荷/高度图以600mm门宽为条件。 | 本案上门约459mm高、单门约434～473mm宽；可先按两只布置估算，最终数量仍按实际门重和具体型号复核。 |

本案四个上柜分别连接四个下柜，各自左右结构侧板承接一组对开门。相邻柜箱保留两块18mm侧板，不能用一个长空箱加八扇门替代。侧板中后部贯通孔350×400mm，孔宽方向沿柜深；594mm侧板有效深度前后各剩122mm。以常见37mm底座定位基准作初步布置时，孔前缘到该基准尚有85mm；122mm是本案预留，不是 Blum 对所有铰链的最小安装要求。

厂家加工仍需核实：门板材质/实重、铰链盖量与杯孔、底座规格、螺钉长度与边距、孔边加固、止挡和实际完整开启行程。拱孔附近结构承载及中转踏板固定未获厂家确认。

50mm北端封板按用户要求保留。当前软件仍检出北端上下柜门开启范围与原斑马帘相交；窗帘未移动。该问题不能用“装86°限位器即可”替代验证，亦未自动标为通过。
