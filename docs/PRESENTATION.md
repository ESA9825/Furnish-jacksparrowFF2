# 方案讲解与交付

入口：顶部“导入／导出 → 方案讲解与交付”，或装修设计工作台的“方案讲解与视角”。原“导出方案成果”也可进入讲解管理。无需联网。

## 使用流程

1. 编辑讲解标题与整体目标。设计意图由使用者填写或确认，不从家具摆放自动推定。
2. 每个重点建立一页，填写需求、设计做法、依据／来源、取舍和施工交底，可关联当前房间及家具。家具沿原稳定 ID 关联；删除对象后提示失联，不自动改指其它对象。
3. 先在主画布调整三维视角，再进入讲解页采集。二维采集为完整、清理编辑叠层的成果图；三维采集沿主生产模型、原相机和活动部件稳定等待接口。保存后可“回到视角”，恢复相机、取景裁切对象及该视角的场景设置。场景设置变化仍沿原 mutate，可撤销；镜头沿本机偏好接口，窗口比例不同可能改变取景范围。
4. 待确认事项记录责任方、结论与依据。选择“确认当前方案”时必须填写依据。它是人工确认，自动空间核对继续独立生成，不互相替代。
5. 完成内容核对后记录交付版本，如“V1 · 布局确认”。新增／修改讲解或方案后提示内容已变更，再记录新版本；记录版本不会自动把待确认事项变成已确认，也不会把旧图变成新图。
6. 导出完整交付、用户讲解版或装修公司交底版。讲解页按阅读对象筛选，用户版省略页内“施工交底”段落；平面、清单、预算及自动核对作为依据继续保留。离线 HTML 可直接打开、打印为 PDF，并下载同次快照中的完整可编辑项目和 SVG。

## 版本与准确性

`work.presentation` 为可选 v1 文档，含 title、overview、pages、issues 和可选 release。旧项目缺失不补写；只有实际保存讲解内容才要求项目／工作区格式94。93及之前沿原默认值读取。沿原 mutate、撤销重做、自动保存、命名方案、复制方案、恢复与项目往返，没有独立保存文件或状态通道。

采图保存当前方案来源指纹、时间、压缩图片，以及三维相机／场景设置。来源指纹读取有效户型及除 presentation、scene3d 之外的工作数据；scene3d由每张三维图独立保存。其它方案数据变化（包括材料、采购与价格）保守要求重新采图及重新人工确认；编辑讲解文字不会清除图片。原空间确认指纹不读取讲解字段，不因文字编辑失效。

方案来源变更或关联对象丢失时，旧图片保留可恢复，但在成果的当前展示中以“图片待重新采集”替代，不把旧图当作当前图。人工确认记录保留原依据，但显示“方案已变更，需重新确认”。恢复到原始方案数据可再次匹配原图和确认；恢复不累计偏移。

release记录版本名、时间和整个讲解文档／来源的内容指纹；导出另列导出时间、户型、活动方案、单位和当次内容标识。指纹用于本机变化检测，不是加密签名或审批凭证。版本记录本身不冻结可编辑方案，也不是发布历史库；**保留导出的 HTML／PDF 和内含项目，才保留当次交付快照**。同一份导出中的图、文字、数据使用同一同步状态。

页面最多24页，人工事项最多100条。图片仅接受内嵌PNG/JPEG，采图最长1280×960以内，逐图最多700 KB字符、全部6 MB字符；大图经JPEG压缩后进入原保存链。未单独存放图片文件，复制／撤销包含图片，会增加快照体积；含多份方案的大项目仍受原导出体积限制。删除讲解页可撤销。

## MCP 配合

新增 `get_presentation`、`configure_presentation`，工具总数由33增至35。源码、桌面传输层和页面须一致；已有桌面需要重启以刷新工具快照，现有聊天也可能需要重载MCP。界面功能刷新源码页面后即可使用。

- `get_presentation` 返回可编辑文字文档、单独的采图元数据与过期状态、当前来源指纹及版本状态，不返回大块图片。
- `configure_presentation` 携带 planId／revision／唯一 requestId，接受完整 presentation、可选 capturePageId、releaseLabel。先读再改，保留其它页与事项；pages内capture省略保留同ID原图，null显式删除。拒绝外部图片及调用者伪造的版本记录；采图沿正式画布，记录版本由应用计算。新页ID由调用者生成并保持稳定。
- 可单独采图或记录版本，也可在一次修改中组合完成。异步采图后再次核对revision；整批验证后一次mutate和原保存回执，重复requestId返回原回执，不重复采图。
- 人工确认须由明确结论及依据支持，reviewKey使用读取的当前sourceKey。不自动把推测写成设计意图，不把模型尺寸说成厂家安装要求。
- 原 `export_artifact(report_html)` 会包含讲解页、有效已采图、人工事项及版本信息，不要求当前停留在3D；它不自动采集新图。

## 边界与验证

图片为模型示意；标注尺寸、厂家资料及现场实测分别表达。DXF仍为布局交接，完整施工节点和专业施工审核不由此功能代替。三维图沿原快速生产画布，未将渐进光追叠加层当作截图；不宣称保存了Cycles渲染、视频、自动讲解音频或自动设计评价。

增量验证入口：`node tests/test-presentation.cjs`；`FURNISH_BROWSER_PATH=<已有Chrome路径> node tests/test-presentation-ui.cjs` 覆盖HTTP与断网file://；`node tests/test-presentation-ui.cjs --desktop` 使用当前打包程序与实际正式文件的隔离副本，核对原文件哈希。运行结果与实际目视记录见 `docs/validation/presentation-20261117/README.md`。
