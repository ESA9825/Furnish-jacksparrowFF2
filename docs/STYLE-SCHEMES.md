# 风格方案：应用范围与独立颜色

2026-11-18：风格方案扩展为六类可选范围。选择预设后，勾选类别并调整取色器，主三维显示临时效果；点击「应用所选范围」进入原保存和一次撤销／重做。取消、结束预览和其它编辑使临时外观恢复。初始只勾选柜体，预览选项不写入项目。

| 范围 | 颜色通道 | 保留的内容 |
| --- | --- | --- |
| 柜体 | 门板、柜身／开放格 | 门板／组件颜色和饰面覆盖、玻璃、五金及结构 |
| 窗帘／纱帘／百叶 | 帘布、纱帘 | 开合、单／双开、安装高度及织物／透光模型 |
| 普通家具／软装 | 木家具、软包、点缀 | 使用现有模型的主色通道，保留其它独立材质；不重染家电、耗材、导入OBJ及未知类型 |
| 门窗框 | 框色 | 建筑固定窗、飘窗窗面、建筑推拉门及已支持配色的门窗产品；玻璃、机构、轨道尺寸保持 |
| 飘窗台面 | 台面面色 | 原台面材料类别、纹理示意、轮廓、厚度和台高 |
| 地板／地砖面色 | 地面面色 | 原材料类别、铺法、尺寸、方向、起铺点、缝宽、标高及预算 |

「仅应用柜体」「应用全部家具配色」继续作为快捷动作，并采用当前取色器数值。「应用配色与地面材料」是另一个明确动作：同时更新配色并沿原房间用途规则替换适用地面材料，预算可能改变；它与只改地面颜色分开。

暖白＋胡桃木补齐木家具中棕、暖灰框、浅色飘窗台及暖米地面。原木、奶油、北欧、工业、新中式和莫兰迪也分别有窗框、台面、地面与纱帘基色。取色器调整只应用到当前对象配置，不另建个人风格库。

## 局部调整

- 房间属性的「地面独立配色」用于本区域。飘窗整体属性提供台面及各窗面的独立颜色；普通建筑窗属性提供窗框独立颜色。
- 局部颜色优先于风格默认，换风格继续保留；「跟随风格默认」只删除对应覆盖。自定义建筑窗按稳定洞口ID／窗面绑定，内置静态户型沿既有窗口索引绑定。不存在的房间／洞口记录保留但不套用其它身份；新建或重划区域不推断旧色归属。
- 家具仍能按原属性主色单独调整；再次勾选该家具类别应用风格会更新家具主色。柜体显式部件覆盖和建筑表面覆盖有独立记录，继续优先保留，不能从旧家具主色猜测“曾手动编辑”的来源。
- 地面颜色在二维作为配色图示，在三维与生产导出中保留纹理、UV和真实铺缝。屏幕色为效果示意，不能替代板材、织物或地面样板。

## 数据契约

可选 `work.styleAppearance`：

```json
{
  "version": 1,
  "floorColor": "#dfd4c2",
  "bayColor": "#eee8df",
  "frameColor": "#615b52",
  "floorOverrides": { "room-id": "#d5c7af" },
  "bayOverrides": { "bay-room-id": "#eee8df" },
  "frameOverrides": { "opening-id:front": "#343b42" }
}
```

三个默认颜色和三份覆盖表都可缺失，缺失保持历史外观；色值严格为六位HEX，每表最多1000项，ID最多500字符。删除最后一项且无默认色时删除整个可选字段。不要补写旧数据默认值。新字段最低项目／工作区／恢复缓存v97，旧版继续读取。柜体仍沿其v96 appearance及局部surface／color，家具沿现有color。产品核心集中范围、角色、字段版本，style-core集中校验、派生及原子应用。

整个结构沿原mutate、撤销／重做、自动保存、命名方案、方案复制、项目与仓库往返；restore严格校验且重复恢复无漂移。颜色不进入空间确认；材料、铺法和实体几何未被当作颜色重写。建筑三维缓存包含已保存外观及临时范围／取色器签名，取消重建原材质；家具使用同一份临时工作副本，预览不会提前写正式数据或预算。

旧地板／石材示意贴图按原材质生成着色图；有真实铺贴时复用原生产材质与UV。新增着色图由相应场景拥有，释放随重建／取消进行，不把每次取色结果加入永久地板纹理缓存。框材继续使用原材质类别和光学参数；未新增全局透明或折射近似。
