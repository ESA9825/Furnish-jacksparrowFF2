# 主三维材质工作区

在三维底栏打开「材质」。点击场景中的地面、裸墙面、可编辑柜体或支持主色的软装，底部显示对应样片。点选样片可直接在当前机位试搭，也可以把样片拖到接受它的表面。可以继续换表面，把多个改动一起应用。关闭或按 Esc 放弃草稿。应用后按原项目撤销、重做和保存。

「铺砖」可跳转到主场景材质。砖规格、缝宽、施工起铺点和标高在铺砖工作区核对。照片样片只更改三维可见饰面，施工图和采购按项目铺贴参数计算。选「跟随方案」会移除该房间的样片及局部面色覆盖。

裸墙涂料保存到实际点选的一侧。柜箱、分区及部件沿用生产构造器已有的外观字段。独立 v2 柜的受支持组件可单独试木饰面，旧分区柜的门板和抽面可试素色。复合柜的整组柜身饰面沿原组级外观，配置里更具体的局部外观优先。玻璃、把手、家电、已铺墙砖及无外观入口的部件不开放编辑。

## 项目与渲染

可选 `styleAppearance.floorSamples` 保存房间 ID 到内置样片 ID，`styleAppearance.wallPaint` 保存墙来源 ID 与侧向到六位颜色。显式设置最低 v105，旧项目无需迁移。内置户型创建编辑副本时，墙面沿既有墙段映射。材质样片从绝对平面坐标采样，房间和所属门洞连续。生产 GLB 读取同源材质与 UV。未应用的草稿停留在主三维。

本机服务直接读取 JPG。离线 `file://` 按需加载由 `scripts/build-floor-samples.cjs` 生成的经典脚本，GLB 导出可读取同源像素。桌面以 1601 正式方案的隔离副本验收试铺、取消、一次撤销重做及刷新。离线浏览器验收实际点选地面、裸墙和柜门，一次应用三处、拖放后取消及生产 GLB。十五项相关核心及保存回归通过。本次验收使用桌面宽度。

## 材质预览的光影

在 Set the Mood 官方网页试用白橡木、洞石和深蓝绒布，并切换正午、傍晚和夜景。Furnish 在材质模式下减弱均匀日间补光，并在机位停稳后增加短距离接触阴影和抗锯齿。画面继续读取方案中的太阳时刻和亮灯配置，退出材质模式后恢复原三维补光。接触阴影为屏幕空间近似，受当前画面可见几何和 WebGL 支持限制。 [Set the Mood 官方演示](https://sael.net/interior/)

地板样片沿用原有实际贴图比例，分别调整粗糙度、法线强度和表层反射。原 800／600 砖的釉面反射在实际砖缝处变弱。支持室内窗洞光照的场景会在掠视角表现窗光柔亮过渡。反射参数用于实时外观，实际材料参数以产品资料为准。生产 GLB 传递贴图及 PBR 表层反射，窗洞亮带和接触阴影由实时视口绘制。

本轮在 1601 隔离副本以同一日照和机位比较原砖、橡木直铺、人字拼和柔光砖，并验证取消后恢复原方案及原补光。离线 Chrome 以隔离夹具复验三类表面的应用、拖放取消和 GLB 表层反射。回归覆盖地面、砖缝、窗洞光照、材质预览及画质模块，未测帧率及窄屏。

## 地砖表面与时段试看

选中瓷砖地面、米色方砖样片或已铺墙砖后，可以切换原砖面、柔光砖、亮面砖和哑光砖。砖规格、砖缝、起铺点和标高读取原设置。「原砖面」移除当前表面的光泽覆盖。换成木地板后，房间先前的砖面覆盖会在重新使用支持的地砖时生效。

光照试看提供早晨 08:00、正午 12:00、傍晚 17:30、夜间 21:00。日出日落读取方案的日期、纬度和北向，夜间按方案的灯具开关呈现。点击「方案光照」、关闭或应用材质会退出临时时段，日照设置仍由原工具编辑。「应用材质」只提交选材草稿。时段对照借鉴了 Set the Mood 的做法。用户提供的小红书笔记因访问限制未取得正文或图片。 [Set the Mood 官方演示](https://sael.net/interior/) · [用户提供的小红书笔记](https://www.xiaohongshu.com/discovery/item/6ae83abd00000000250111db?source=webshare&xhsshare=pc_web&xsec_token=ABBXdkJ3rA5fc3fAtbYCibkKk-rn90MQ33S9RllzUaHOk=&xsec_source=pc_share)

`styleAppearance.floorTileSheens` 按房间保存 `satin`、`gloss` 或 `matte`，显式设置最低 v106，旧方案沿用原材质。GLB 传递颜色、适用的法线和对应的粗糙度、表层反射。实时画面按房间实际窗洞计算近似反光，亮面保留窗格轮廓，柔光扩大高光过渡，哑光显著压低反光。窗格反光受相机位置影响，支持相邻阳台的 1601 客餐厅窗光。布帘和家具的镜像遮挡未纳入该近似。光泽和粗糙度为选材预览参数，具体商品数据由厂家提供。

1601 桌面副本通过同机位正午三类砖面对照、傍晚及夜间试看、取消、应用、撤销重做和保存后重载。离线直接打开通过切换试看时段、一次应用地面及其他表面、拖放取消、刷新和 GLB 贴图及表层反射回读。增量回归覆盖几何不变、内部窗光、砖缝预览、工作区兼容和旧缓存恢复。未执行全仓和窄屏验证。

## 批量瓷砖与美缝

在「材质 → 批量瓷砖」中选「墙砖和地砖」「地砖」或「墙砖」，选择面色和光泽，再在「美缝」输入色值或选「跟随砖色」。同一份三维草稿可调整多个范围，点击「应用材质」后一次保存和撤销。也可在「点选表面」编辑单处。批量范围是现有瓷砖地面与已铺墙砖，锁定表面会在范围计数中提示。瓷砖照片里的砖缝属于贴图本身，改色效果以使用实际砖缝的程序瓷砖为准。

「铺砖」里的砖长、砖宽、缝宽、起铺点、分带和标高继续使用原参数。美缝由原 `tileGrout` 记录，直接改色时解除所选表面的美缝组关联，其它预设组继续跟随。墙砖面色和光泽沿实际墙侧绑定存入 `styleAppearance.wallTileMaterials`。项目、工作区和恢复缓存可读取旧版本，带墙砖材质时最低 v107。

1601 桌面副本以 9 处地砖、32 面墙砖验收全屋预览、取消、一次应用与撤销重做、正式保存及重载。Chrome 本机服务及离线 `file://` 验证范围切换、实际墙地砖渲染、预设组保留和项目往返。本轮执行增量检查，未执行全仓及窄屏验收。
