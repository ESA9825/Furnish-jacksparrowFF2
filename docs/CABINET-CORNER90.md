## 使用与数据

家具库「厨房与壁柜」增加「90° L型转角柜」。单独打开时提供平面、A/B两边正视和三维检查；组合厨房左侧也可安装整体转角组件。参数面板编辑整个转角，生成板件在结构树中可选中核对，不独立拖动改形。可保存整体至家具库复用；嵌入厨房后仍保留参数，连续台面由厨房宿主统一管理。

持久格式为 `type:cabinet`、`cabinet.version:3`、`shape:corner90`。两边外长复用家具 `w/d`，自身高度复用 `h`，柜底离地复用 `mountHeight`。输入均为mm；旧v1/v2柜体与保存结构不自动迁移。项目最低v93，工作区也兼容v94讲解功能。

| 参数 | 含义与当前软件范围 |
| --- | --- |
| w / d | 从同一个外墙角计量的两边外长，300–1200；前沿各至少120 |
| depthA / depthB | 两边总深，180–900；分别小于对应外长 |
| hand | 左／右回转；与整件家具镜像独立 |
| h / mountHeight | 自身高度400–1200；离地0–20000，实体和扫掠只叠加一次 |
| thickness / backThickness / plinth | 结构板厚12–30、背厚0–50、踢脚0–250；有调节脚时至少40 |
| panelMode / top | 顶底一体L板或分段；顶部完整板或四段横撑 |
| shelves / shelfMode | 至多8层；按板底绝对柜内标高排序，连续或分段，固定／可拆卸 |
| shelfSetback | 前退0–100；层板实际退让、板厚与净高由同一核心生成 |
| base | 调节脚＋退40踢脚，或实体L形底座；地脚避开踢脚实体 |
| door | 门缝、主副轴演示限位、先折后开／同步路径、进度及开关；仅hardware:layout |

上述范围是当前实现的输入校验，不是厂家可生产尺寸或推荐门宽。关闭门时，两片宽度分别从 `w-depthB`、`d-depthA`扣除相应门缝派生，不能自由改宽破坏闭合关系。UI分别显示两段前沿、门宽与真实层间净高；默认830高／100踢脚／18板／450层板时净高332、344。门面上沿距柜顶1mm，与相邻标准柜一致，覆盖顶板前缘；门高728，不再沿用原型710高而露出18mm顶板。

## 生产构造

`corner-cabinet-core.js`为唯一参数源，派生临时v2生产部件后复用现有构造器、稳定部件身份、双轴门、实体记录、SVG和扫掠；不保存派生boxes。连续顶底和层板均是带凹角的真实单个网格，没有用外包矩形填满空口。背板在外角交接，端侧板在顶底之间，柜腔没有额外内角竖板。

分段模式实际生成两段板和底部一片连接片示意。连接片数量、螺钉、地脚承载及石材支撑尚未工程验算；顶撑、分段层板不能自动视为任何尺寸石材的合格承托。活动层板保留实体与碰撞，只标为可拆卸，不擅自推定可从门口取出。

产品范围、默认参数与语义版本放在product-rules；参数变化进入空间指纹，颜色、价格及可拆卸标记不清除空间确认。恢复、复制、替换清理、命名方案、项目、家具库及缓存沿原通道。编辑仍通过mutate保存和撤销；组合内转角柜通过完整参数替换保留结构，不降为旧柜列配置。

组合厨房按真实两个朝向加入正视图，允许共用原柜边正视；缺少的朝向另列视图。台面支撑轮廓使用L形和两个前沿，未将缺口当作有柜体。既有v2组件MCP接口仍只编辑其明确列出的v2模块；v3可用完整cabinet/kitchen配置接口，界面提供参数编辑。
