## 小米中枢网关与断网

京东 SKU 100020318833 对应小米中枢网关 ZSWG01CM，以到场铭牌为准。米家中枢把符合条件的自动化保存到本地，并通过蓝牙或局域网调度设备。Wi-Fi 设备和中枢通信依赖局域网，蓝牙 Mesh 设备需要实际处于中枢可调度的网络内。某条自动化是否属于本地执行，以米家规则显示和现场实测为准。 [京东产品页](https://item.jd.com/100020318833.html) · [米家中枢网关产品百科](https://home.mi.com/webapp/content/baike/product/index.html?model=xiaomi.gateway.hub1) · [米家中枢与网关使用指南](https://home.mi.com/views/article.html?articleId=713752525000000001)

| 验收工况 | 操作及预期 |
|---|---|
| 外网断开，局域网、网关和用电设备正常 | 对已配对的门口和床头面板逐键测试，确认灯切换、窗帘开停关及两端交替操作。分别记录每条规则是否本地执行和实测结果。 |
| 局域网或 Wi-Fi 中断 | 检查墙面负载键和有线双控。跨 Wi-Fi 的窗帘自动化需恢复通信，使用经验证可用的原厂遥控。 |
| 唯一中枢断电或重启 | 检查直接负载键、有线双控、独立感应夜灯、本地呼叫和窗帘原厂遥控。由此确认现场仍能使用哪些操作。 |
| 停电及恢复 | 记录灯具上电状态、电机恢复后的行为和系统重新入网后的响应。 |
