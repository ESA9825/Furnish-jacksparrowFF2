# 分阶段维护验收

## 大工作区保存

用正式快捷方式对应的同一 Electron 桌面包打开 1601 的隔离副本，保留 290 件家具和 22 份命名记录。正式存档约 201 MiB，实际发送的紧凑快照约 85.6 MB。上次观察到的间歇失败本次正常基线未稳定复现。

完整副本连续编辑并保存三次，重开后核对正式文件和 IndexedDB。分别模拟浏览器缓存挂起后失败、正式文件写入被拒绝。浏览器缓存挂起时仍可成功提交正式文件。文件写入失败保留具体错误与编辑，恢复连接后沿原保存入口重试。Chrome 离线直接打开后验证了缓存合并、清除的事务顺序和普通保存。16 项增量测试通过，涵盖旧版本读取、冲突、丢失回执、恢复与本地缓存。

## 3D 主灯

同一完整副本和固定机位，使用实时流畅观察。测量从主灯按钮点击到开始首次渲染，以及通过 View3D 检查到场景可拍摄的时间。建筑重建次数取自正式构造入口。

| 操作 | 首次渲染开始，改前 → 改后 | 可拍摄，改前 → 改后 | 建筑重建 |
| --- | --- | --- | --- |
| 首次开灯 | 1710 → 293 ms | 5.19 → 4.52 s | 1 → 0 |
| 关灯 | 586 → 308 ms | 1.64 → 1.23 s | 1 → 0 |
| 再开灯 | 1615 → 294 ms | 3.56 → 0.37 s | 1 → 0 |

该次首次亮灯约 3.31 秒完成灯带补光。直接光和发光面优先更新，视口提供补光状态。目视检查同机位的灯带、灯具和墙面；核心回归核对发光面开关、遮挡负例、补光计算取消及切灯复用实体。时延为这次实测，渲染和后台保存可能产生额外长帧。

## 方案与历史备份

经 Furnish 本机接口读取正式 1601 的保存状态、版本和空间问题。竖向交叠、柜门／抽屉使用空间与设备正面预留补做本机复尺记录。在独立数据计算中对比包覆柜高度及基站周边方案。实测高度与五金开启范围仍须现场核对，正式方案保持原布置。

抽取早期、中期及最近三份真实历史，将其复制后无损压缩。约 448.2 MB 降至 36.0 MB，逻辑 ID、下载字节、恢复结果和重开后的文件修订通过验证。正式的 72 份历史约 10.76 GB，按样本比例估计潜在节省约 9.9 GB。压缩仅在隔离副本执行，估算不计入整盘已释放空间。

本轮采用相关增量检查。未执行全仓、窄屏、Windows 或完整高清出图验收。
