# 渐进渲染内核优化与本机对照（2026-11-17）

结果：采用带回退的场景特化、空介质队列跳过和原位FP32累积，当前机位与厨房近景的正式代码ABBA分别减少约11.0%／11.3%耗时。精细档、实际材质、贴图与光照保持。没有得到倍数提速，也不能据此把剩余时间归因于M6物理上限。

## 输入、口径与结果

Apple M6／12核GPU／24GB。本次先通过Furnish MCP只读确认当前方案与机位，再固定复制正式工程；每组从该副本只导出一次生产GLB，各轮使用同一份字节。真实打包Electron在独立工作目录、端口与缓存内执行，测试器核对固定输入前后散列。正式方案没有写入。

统一1200×846、256采样、8反弹／16透明反弹、原辐射单位、ACES曝光、直接／间接clamp与原OIDN引导权重。当前保存的日景11:45、顶灯开启；未为了计时改成夜景或调亮暗部。当前机位水平65°，相机约(-559,2151,7489)mm；厨房水平75°，相机(9250,9100,1660)看向(7600,9050,1250)mm。同场景的不同机位分别比较，不混算。

计时从预览iframe创建至完整256采样、降噪及GPU完成通知，包含解析、BVH与编译；不含此前单列的生产快照时间及通知后的PNG采集。按原路径→优化→优化→原路径运行，避免只选最快一帧。`legacy`通过关闭本iframe的特化配置保留供应库原通用路径，不改变输入材质；`production`使用最终正式实现。

## 瓶颈与采用的改动

当前机位原版采集的GPU内核时间中，Logic约36.2%、Material约29.5%、射线求交约19.9%、阴影求交约5.5%、介质队列筛选约8.1%。这是抽样计算内核分布，不含所有纹理复制／合成，不是整芯片利用率；CPU renderSample累计和约0.7秒快照、约0.1秒降噪不是主要瓶颈。

1. **只折叠整场景确实未用的材质功能和贴图槽位。** 实际正值、贴图或未知／非有限参数保留通用代码；清漆、玻璃透射、IOR、所有实际贴图及几何法线保留。检测在GLTF完成读取、灯光组装后进行，每个iframe只拥有一份不可变场景。相机更新复用检测；场景改变创建新iframe并重新检测。
2. **无体散射时跳过空介质队列及相应状态分支。** 当前全部实际材质的scatterStrength为缺失默认0或明确0，且无fogVolume。显式undefined、NaN、负值、正值或fogVolume保留原路径。玻璃的Beer透射衰减不是体散射，相关函数与分支继续保留。
3. **支持时在原FP32纹理中累积。** 原实现每次路径迭代复制整幅图，再交换两张纹理；像素池对每个像素最多持有一条活动路径，因此同一次Logic派发内不会有两个槽写同一像素，可直接保留未改写像素并在原位置累积。检测到`readonly_and_readwrite_storage_textures`才启用，其他设备继续原双纹理路径。未改为FP16或降低任何采样预算；访问方式依据[WGSL存储纹理规范](https://www.w3.org/TR/WGSL/#storage-texture-types)。

五个供应模块的适配由`scripts/lib/lighting-preview-patches.cjs`严格校验原本地改写源散列后生成，现有vendor脚本复用该阶段；manifest保留原包源散列并记录patchSet=1及适配后散列。五个模块已从保留的原始输入逐字节重现。未知新版本拒绝静默套用补丁，回退场景不强制禁用真实材质能力。包版本、许可证、运行时离线入口和数据格式未改变。

## 未采用的实验

本轮共44帧精细档GPU试验／正式对照，所有已计时帧均完成，另将一致性失败单列：

- 只去掉整图复制：约1–2%；只跳过介质：约5%；组合约10%，继续加场景特化后在正式代码约11%。这些幅度不相加。
- 逐字段读取路径状态：没有稳定优势；材质拆成普通／玻璃清漆两个内核：约28.74秒，未优于约28.26秒完整特化组合。
- 灯光选择缓存权重：单独约31.98秒，组合没有增加收益，局部数组并未带来期望改善。
- 正交基转置替代通用求逆：单独约32.14秒，无实测收益，未引入正式数值路径。
- 灯光常量预计算首版因扩展缓冲步长后整数源索引错误而明显改变图像，**一致性失败，不能采用其27.33秒数字**。修正后复验图像通过，但组合约28.59秒仍未优于更简单方案，也未采用。

失败候选没有进入正式vendor。剩余主要成本仍在GPU路径／灯光／材质和软件BVH遍历；未测得能够在这些画质约束下继续显著领先的其它候选。
