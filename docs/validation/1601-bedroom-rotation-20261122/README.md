## 定位与修复

基线主卧两次 Chromium 时间线显示，127.4 和 131.2 ms 的最长绘制间隔分别包含 122.1 和 125.3 ms 的 `workflow-tools.js` 自动空间核对回调 `advance`。回调运行时，新的指针事件和动画帧在同一主线程排队。对应两轮旋转单次 WebGL 提交最大约 5.4 和 4.2 ms。空间核对原先有切片预算，但单次迭代器推进可能超过预算，它已有二维拖动暂停条件。

用新隔离缓存直接先测次卧，也捕捉到同一回调。基线最长绘制间隔 155.2 ms，其中 `advance` 占用 148.6 ms，相邻的 WebGL 提交耗时约 3.8 ms。改后记录中，旋转期间该回调从 54 次降为 0 次，最长绘制间隔为 18.1 ms。

主三维通过现有画布指针、相机动画和飞行状态通知自动空间核对。手势进行时暂停，若迭代已开始则放弃这次未完成读取，空闲后按最新代次重新启动。暂停在切片边界生效，已经进入的同步步骤仍需返回。手动核对沿原入口执行。以同一视图状态继续使用原照明、阴影缓存、吸附与撤销链。
