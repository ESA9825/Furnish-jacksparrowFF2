## 生产与空间核对

Blender 5.3.0 单型号管线通过作者预检、坏资产负例、独立发布、空间／项目往返、HTTP 与断网 file://、正式 GLB 逐件回读、三机位和下载工程重开。正式桌面放置后查看侧视，壳体贴壁、手柄朝向过道，现有落地绿植的叶片伸入转动区域。

扫掠复核从生产零件顶点提取臂、握头和握柄轴各自的离墙区间与径向包络，把实际叶片/枝条三角面裁进对应区间后，与绕轴 360° 的包络比对。用当前姿态得到落地绿植干涉，花架末端两盆吊兰不在扫掠内。保持墙上点位不变，将落地绿植离墙再移 150 mm 的模拟中，外扩 30 mm 的手部空间也无相交。该空间是布局估计，仍需实物试摇。

E46 核对比较垂直明线的平面投影与实际开关面板边界。沿窄墙直上，原顶内侧转向右端吊座，最接近面板外缘约 140 mm。墙内开关暗管、真实下线槽、转角器和绳长未实测。
