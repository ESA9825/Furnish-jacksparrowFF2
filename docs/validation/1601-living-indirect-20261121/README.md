# 1601 客餐厅第四轮间接光与软阴影

2026-11-21。使用 1601「方案34电气布点 · 适老与全屋控制」的完整桌面隔离副本，以 `53623328` 为改前基线。仍用第三轮的原布局、窗洞、曝光、11:00 日景和关闭的主灯。

## 显示改动

- 在已有的 256 × 256 房间遮蔽纹理中加入墙角遮蔽。只有两组不同方向且实际接地的墙附近才会形成角部衰减。保留原墙脚接触阴影，独立过梁和开门洞维持原来的排除规则。相邻墙面下部加极弱的暖色回光。
- 松绿沙发背后的暗部分布由实际沙发位置、朝向、宽深高和地面标高控制。沿靠背上方和两端渐退，随沙发位姿更新。沙发隐藏、整体家具隐藏或沙发抬高时停用这项暗部。预览未生成虚拟发光体。
- 餐边柜操作凹位使用生产 `operationBack` 板件的统一局部坐标。背板上沿趋暗，下部保留少量暖色回光。服务开口造成的分板沿用统一位置范围。显示没有触及玻璃、五金、生产网格和其他柜门材质。
- 在客餐厅的地面、素墙和适用柜板上扩大已有太阳阴影的采样跨度。沿用原阴影贴图、采样数和更新时机。墙面材质、角部遮蔽与太阳阴影范围共用同一次遮蔽纹理读取。新增光照是局部实时近似，全程使用「流畅观察」的 WebGL 路径。
