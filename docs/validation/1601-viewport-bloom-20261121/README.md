# 1601 第六轮夜景 Bloom

2026-11-21。在 1601 三维选「流畅观察」，打开「显示 → 夜景、主灯、灯具柔光 Bloom」。正式方案的「灯」图层在验收前为隐藏，查看吸顶灯时在图层管理中显示它。试验默认关闭，开关独立于 GTAO 并存入本机偏好。

## 渲染与操作

- 从 1601 已安装的吸顶灯、筒灯、吊顶灯带及其柔光板、餐边柜发光条提取已点亮的表面。吊顶灯带在眼高位置部分藏在型材内，额外复用这条灯带已有的受光遮挡蒙版，提取天花上最亮的窄带。代理网格沿用原模型、裁切和深度。任意高亮材质不参与提取。
- 颜色与深度沿 GTAO 的同一场景绘制。Bloom 在半分辨率提取、四分之一宽高做两次可分离模糊，合成中限制逐通道增量。校正 r160 离屏目标的纯色背景清除色。无法创建 Bloom 目标时可回退并继续使用 GTAO。
- 1601 夜景在按住画布旋转、平移和移动家具时临时采用最高 1.25 DPR，指针释放后恢复最高 2 DPR。原投影和拾取坐标沿用 CSS 尺寸。直接拖家具时沿用灯光阴影缓存，接地近似跟着家具更新，释放后重绘阴影。上述交互设置在开关两组相同。

使用同一正式 1601 工作区的隔离副本。两组均为 21:00 夜景，打开主灯及「灯」图层，关闭夜灯，GTAO 固定关闭，使用 WebGL 光栅渲染。眼高约 1.60 m，坐标包含完成面标高。

## M6 实测

同一打包 Electron、ANGLE Metal Apple M6，依次关闭、开启、开启、关闭。静止画布 2840 × 1554，手势移动生效时为 1775 × 971。每项手势发出 72 个鼠标位置，每轮捕捉到 46 次有效茶几位置变化。客厅定帧 4241 → 4248 次绘制，增加灯具掩码、两次低分辨率模糊及一次合成。场景本体绘制一次。

| 指标（ms） | 关闭两轮 | 开启两轮 |
| --- | --- | --- |
| 旋转绘制间隔 P50 | 18.5 / 18.7 | 19.4 / 19.5 |
| 旋转绘制间隔 P95 | 31.9 / 34.8 | 23.9 / 22.3 |
| 平移绘制间隔 P50 | 19.1 / 18.9 | 19.8 / 19.9 |
| 平移绘制间隔 P95 | 35.2 / 39.8 | 21.7 / 23.0 |
| 拖动绘制间隔 P50 | 28.5 / 28.2 | 28.5 / 28.3 |
| 有效拖动输入至 WebGL 提交 P95 | 26.4 / 25.9 | 26.6 / 26.9 |

两组都有个别旋转或平移长帧，数据仅反映这四轮。拖动中所有超过 50 ms 的绘制间隔均包含至少一次保持同一吸附位置的输入。输入至提交包含吸附计算，显示器出光延迟未测。

## 验证

用 `scripts/verify/verify-living-furniture-raster.cjs` 复现，设置 `FURNISH_RASTER_BLOOM=1`、`FURNISH_RASTER_PAN=1`、`FURNISH_RASTER_RUNS=before,after,after,before`、`FURNISH_RASTER_CAMERA`、`FURNISH_RASTER_SECOND_CAMERA` 与 `FURNISH_RASTER_GESTURE_CAMERA`，相机采用上表数值及 `mode: 'orbit'`，基线参数为 `7601ff28`。开关比较读取同一版源码。

通过渲染目标尺寸、资源释放及回退测试，复跑灯带遮挡、场景阴影缓存和室内日光。桌面验证 Bloom 偏好刷新、茶几撤销重做、隔离存档及生产 GLB。断网 Chrome 从 `file://` 验证夜景开关、GTAO 两种状态下切换 Bloom、关闭后恢复原画面，光照预览的本地模块图也通过检查。正式 1601 文件哈希一致，已清理登记的可重新生成资源。手机、窄屏、光追和全量测试未执行。
