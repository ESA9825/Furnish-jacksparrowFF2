# 1601 厨房推车的 3D 拖动设置

2026-11-22。3D「显示 → 3D 场景」新增「拖动吸附」和「碰撞检查」两个独立按钮，默认开启，各自沿本机界面偏好保存。恢复默认视图设置会打开两项。

- 关闭拖动吸附会直接按当前移动步长取整，跳过贴墙、家具对齐、柜内吸附及这些步骤需要的几何推导。
- 关闭碰撞检查会跳过柜内候选和吸附终点的实体板件相交筛选，以及单件松手时的防穿墙处理。柜内候选仍按原宽深、标高、朝向和捕获范围筛选。开关作用于 3D 平面拖家具。2D 编辑辅助、漫游碰撞、预留和空间核对沿各自原入口生效。

## M6 同机位、同轨迹实测

使用实际 Electron 桌面程序及 ANGLE Metal Apple M6，沿[厨房推车隔离副本、原机位及 72 步轨迹](../1601-kitchen-cart-drag-20261122/README.md)。所有组合使用同一份新代码、独立桌面配置及原 248 件家具快照。流畅观察，21:00 亮灯，曝光 10，移动步长 10 mm，关闭低位夜灯、GTAO、Bloom、SMAA 和光追。关闭 Chromium 追踪。

顺序为两项开启、只关吸附、只关碰撞、两项关闭、只关吸附、两项开启。数据为 ms，斜线分隔重复轮次。

| 3D 拖动设置 | 有效输入到新位置提交 P95 | 28 个共同有效输入 P95 | 绘制间隔 P50 | 最长绘制间隔 |
| --- | --- | --- | --- | --- |
| 两项开启 | 30.0 / 31.4 | 30.3 / 38.4 | 23.2 / 24.7 | 110.0 / 116.0 |
| 只关吸附 | 19.5 / 13.5 | 19.5 / 11.0 | 17.6 / 17.0 | 150.2 / 150.2 |
| 只关碰撞 | 29.0 | 32.8 | 22.6 | 110.6 |
| 两项关闭 | 18.3 | 18.3 | 17.7 | 150.1 |

输入延迟从 Chromium 事件时间戳计到对应新位姿的 WebGL 提交结束。吸附开启时有 42 次有效位移，关闭时有 36 次，各组合均有 28 个相同输入序号产生位移。关闭吸附后，单次定位计算 P95 为 0–0.1 ms；两项开启时为 14.3 / 15.8 ms。关闭吸附后的最长绘制空档约 150 ms，期间前八次输入仍落在同一 10 mm 网格位置，第九次提交新位置。

所有实际指针坐标、地面投影和起点逐步一致。开启吸附的轨迹和上轮优化版逐点一致，单独关闭碰撞也得到相同位姿，单件落点为 (7031.2, 8916) mm。关闭吸附时 72 个输出全部符合 10 mm 步长，单件落点为 (7030, 8920) mm。实测松手时的防穿墙调用在碰撞开启时为一次，关闭时为零。柜内板件筛选另以真实层板妨碍设备的用例验证，退出时的撤销与分辨率恢复通过。

六轮均检查两个开关默认开启、实际点击、2D 偏好和项目工作态一致。重载与再开启的补测位于 `output/desktop-verification.noindex/room-raster-y0ol1p.noindex/`，留有两态菜单图片。该次两项关闭的附带测量为输入 P95 25.4 ms、最长绘制间隔 153.2 ms。语法检查及八项相关 Node 回归通过，验证范围为常规桌面。全量、窄屏及光追验收未运行。

本机统计为 `output/desktop-verification.noindex/room-raster-7B5jnu.noindex/results.json`。将 `FURNISH_RASTER_ROUND` 设为 `drag-snap-toggle`，`FURNISH_RASTER_ROOMS` 指向 [厨房机位](../1601-kitchen-cart-drag-20261122/rooms.json)，运行 `scripts/verify/verify-living-furniture-raster.cjs`，参数为同一隔离副本和基线 `a5d50ad4`。本轮各组均使用当前版本。

两组隔离运行的源文件哈希一致。运行结束后按测试归属清理临时源码、资源与缓存，保存隔离方案、界面图片和逐步数据。
