# 1601 客餐厅材质与窗光两轮精修

2026-11-21。以 1601「方案34电气布点 · 适老与全屋控制」为实测场景。两轮分别观察材质变化和同材质下的窗光变化。先检查历史用户图中的松绿细条绒、暖色樱桃木和素白岩板，再以正式渲染器的眼高画面调整。材料反射与纹理密度为展示估计。

## 第一轮：表面材质

- 松绿灯芯绒保留保存色作为款式识别，按既有参考图校准渲染中间调，扩大原条绒漫反射和法线对比，增强掠视绒光。沿用相同条距、软包几何及生产构造器。
- 茶几木纹加入弯曲年轮与木孔的宽窄层次，纹理用 Mipmap 后共用。白岩板保留素白基色，粗糙度有细微变化。位图以同一张 glTF 金属度／粗糙度贴图导出，金属度系数为 0。
- 正式方案客餐厅、阳台和餐厨过厅存的是暖色 800 mm 地砖。原色中叠加较轻的灰度云纹，砖缝色与现有砖宽沿原逻辑。显式铺贴布局继续走原铺贴构造；试验不换地面类型。
- 改前 `f85bdc9c`，改后 `3107a99f`。同一 11:00 日景、机位和曝光可见沙发绒面及茶几木纹差别。岩板粗糙度变化更适合在窗边斜看。

## 第二轮：窗光与反射

- 客餐厅连通阳台的主窗和侧窗使用原实际洞口、房间范围和衰减图。按太阳高度对户内漫反射补光重新分配、对透过开口的亮部暖化，并添加较弱的地面反弹光近似。房间间沿用已有衰减图约束。
- 素面岩板与缎光砖的反射使用实际洞口范围及粗糙度扩散。地砖以掠视角为主。晚间或日照低于地平线时沿原夜景路径。没有增加全屏渲染通道、阴影光源或碰撞部件。
- 用 `3107a99f` 作改前。前后分别锁定同一时段比较，再在第二轮固定材质分别观察 08:00、11:00 和 18:15。时段通过真实日照滑杆的预览事件输入并恢复旧值，未写入项目。
