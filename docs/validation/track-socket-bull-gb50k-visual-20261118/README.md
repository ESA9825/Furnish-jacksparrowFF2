## 生产复核

- 作者预检、六种独立故障注入及正式离线发布通过。发布 GLB SHA256 为 `ce4c540e87aeb78a425484004e6d276caaf2dc36485118bc53a00cfd84801377`，源 BLEND SHA256 为 `454a4d0d4ac1802588b2b6afe0f35ce1ec1aa5d73594bd7496d83a9a1f0b8c9a`。
- 单型号空间与状态验收覆盖真实实体、外部净距、包含、重叠、高度分离、离地编辑、旋转镜像、重复恢复。独立测试核对三个面盘上的 15 个真实孔洞、贴面定位及核对摘要。
- Chrome 本地服务及断网 `file://` 通过 23 件带稳定身份的正式 GLB 导出。Blender 回读各件世界边界；HTTP 另核对缩放、撤销重做、刷新和窄屏。
- 自动 Metal 第一机位停滞，测试独立进程已结束，改用 CPU 跑同一型号。
- CPU 重跑通过，三个 512×512 机位及其下载的 BLEND 重新打开。目视检查确认深灰面盘、轨道凹槽、模块遮挡和背面装贴平面保留。[正面](production-front.png) · [斜视](production-oblique.png) · [背面](production-back.png)
- macOS 快捷方式对应的 Furnish 桌面程序在独立目录、端口和缓存中验证了家具库添加、二维图形、底部离地编辑、撤销／重做、插座点位、390 px 窄屏、保存刷新及正式 23 件导出。测试实例退出时停滞，结束本次独立进程后复查原工作区文件 SHA256 一致。用户方案、隔离保存文件、浏览器持久存储与本地截图保留。
- 其余型号整链路及全量项目检查未执行。静态模型无机构端态；未核对实物颜色、安装净距或接线。
