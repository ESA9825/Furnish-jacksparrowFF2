# 1601 第十轮餐边柜细缝

2026-11-21。针对现有餐边柜不透明门面横缝，读取实际门板局部上下边界，按视口内约一个像素的投影足迹轻微降低边缘漫反射并提高粗糙度。物理范围限制为 0.8 至 5.5 mm，视口很近时减弱。继续使用原生产网格、面板间隙和拾取。新处理属于主画布材质着色。

首版同时处理横竖方向。以同一轨迹的相邻三帧 RGB 二阶差分绝对值均值比较，横缝区 1.875 降至 1.857，竖缝区 2.816 升至 2.996。正式版只采用横向处理。该读数包含正常位移，用于同一轨迹和取样框的比较。

## 同机位与轨迹

采用第八轮客餐厅的眼高机位和茶几手势机位。两组均为 21:00 夜景，主灯和「灯」图层可见，关闭夜灯、GTAO、Bloom、SMAA 和光追。在旋转时的 1775 × 971 画布上按 −0.052 至 +0.052 rad 共取 29 帧。逐帧对照相机位置、目标和绘制尺寸。窗框和灯带裁切用作控制区。

正式版横缝区域的相邻三帧数值为 1.875 → 1.840，改善约 1.8%。竖缝样区、窗框与灯带控制区的 29 帧逐像素一致。全柜门裁切区变化轻微（1.889 → 1.886），适合按正常看房尺度保留。取样框以 533 × 413 px 餐边柜裁切左上为原点，横缝 x 100–459、y 270–312，竖缝 x 193–271、y 105–279。
