# 1601 第九轮材质随视角的表现

2026-11-21。沿用第八轮的局部回光。客餐厅的松绿绒面增加随掠射角变化的低强度反射，白岩板采用较宽的窗光和灯光高光，并略收实时预览的漫射亮度。茶几樱桃木和餐边柜木背板使用带基色的柔和响应，素色柜门保留较窄的缎面高光。光源由现有窗洞和各房间可见的主灯派生。着色变化只应用在生产编辑画布，不增加绘制通道。

## 日夜同轨迹

固定视点绝对标高 1660 mm。客厅位置 9530 / 5320 / 1660，目标 7700 / 4100 / 710，水平视角 68°。餐厅位置 9320 / 6180 / 1660，目标 8060 / 7530 / 1520，水平视角 82°。在每个机位绕同一目标水平旋转，从 −0.095 至 +0.095 rad 均匀截取 29 帧。逐帧核对前后相机与画布尺寸。

11:00 日景关闭主灯。21:00 夜景打开主灯和实际「灯」图层。GTAO、Bloom、SMAA、夜灯和光追均关闭。绒面、木饰面及缎面柜门的变化较易见。强照度下岩板面心仍接近白色，掠射高光的差异主要出现在边缘与观察角度变化时。

复现用 `FURNISH_RASTER_ROUND=material-response` 和第八轮的桌面验收脚本，基线 `560913fd`。日景对照再设置 `FURNISH_RASTER_SCENE=day`。
