## 测量

本机打包Electron、正式1601工程的隔离副本，固定客厅机位、夜景、同一光源和曝光：`output/desktop-verification/progressive-view-aYtYhp`。快速档800×449／64采样，约9.323秒；精细档1200×674／256采样，约55.120秒。均到OIDN完成，约5.9倍；快速档从相机设置后计时，精细档从切档计时，均含各自准备成本，非纯GPU基准。第二次同机位复测为9.566秒与55.335秒（`progressive-view-dIOork`），约5.8倍。顺序测量，精细档可能受缓存影响，不当作各场景稳定倍率或硬件评级。另一快速档测得约11.844秒。

已实际查看快速档完整收敛截图：吊顶光带、窗帘、沙发、家具轮廓正常，放大后画面偏柔，窗外及暗部仍有噪点。未把快速观察当作最终成片。
