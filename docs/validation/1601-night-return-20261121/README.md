# 1601 第八轮夜景回光

2026-11-21。1601 客厅和餐厅在夜景开启主灯时启用局部回光。光源来自在对应房间实际向下发光、可见的生产灯具。取发光面功率及地面基色，生成房间平面上的 80 × 80 漫反射近似。能量随位置衰减，在房间边界约 0.52 m 内渐隐。

顶面是主要接收面。上部素墙与不透明柜门只接收少量漫反射。已有直射光、灯槽蒙版和曝光沿原通路。光源隐藏或关闭时撤去回光。回光图在布置或可见光源变动时更新，旋转和平移复用。正式画布沿已有材质着色器计算回光，未增加绘制通道。

## 对照

同一正式工作区的四个隔离副本，21:00 夜景、主灯与「灯」图层开启、夜灯关闭。GTAO、Bloom、SMAA 和光追均关闭。采用第六轮两个眼高机位和茶几手势机位。首版顶面亮度提升较大，餐厅顶面分区可见明显直边。正式参数收敛顶面上限并加入房间边界渐隐。

餐厅灯罩右侧顶面的抽样平均显示亮度从 17.34 增至 49.18（8 位 RGB 加权）。客厅墙面和餐边柜门的代表性抽样分别只增加 0.05 和 0.54，远处厨房及窗内样区逐像素一致。餐厅回光带在离开对应地面区时渐隐。图像里仍有正常的未受光暗部。
