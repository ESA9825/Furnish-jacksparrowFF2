## 同机位外观对照

Furnish macOS 桌面，日景 11:00，首组相机位置 (6170, 4310, 1950) mm、目标 (4940, 3260, 510) mm、水平视角 67°。对照检查圆柱端头、直板床头和灰绿色被面的垂落及遮挡。

| 阶段 | 检查与处理 |
| --- | --- |
| 轮廓与结构 | 原布置用软靠背示意床，新模型改为连续木质床头、独立圆柱与分离式箱帮。四格隔墙、底板与闭合五金保留在生产床架中。 [原布置](desktop-before.jpg) |
| 布面与木色 | 首轮出现床垫穿过被面波谷和床尾褶边。将下垂起点移至床垫外侧，抬高波谷并调整木纹着色。相同机位复查时，被面与床尾遮盖连续。 [首轮](desktop-first-pass.jpg) · [修正后](desktop-refined.jpg) |
| 次卧放置 | 用广角查看床架、边几、窗帘和电视墙。模型床尾至墙约 436 mm，至电视平面投影约 356 mm。基于估算床架尺寸核对，局部空间工具仍列床架、床垫和被子的三组叠放提示。 [最终广角](desktop-composition.jpg) |

## 生产验证

- Blender 5.3.0 验证三件新模型的预检、独立发布、HTTP／离线加载、生产 GLB 回读、三机位出图及下载工程重开。实际部件数为床架 58、床垫 4、被子 2。 [生产床架斜视](model-oblique.jpg)
- 桌面隔离副本搜索「半夏」得到三个新条目，加入床架后保存并重开。组合以 ID 和部件键核对四件生产导出。完成地面基准 60 mm，床架、床垫、枕头、被子的世界高度范围分别为 60–1060、460–620、620–720、470–655 mm。
- 同一户型快照建立前后两份隔离副本，正式方案没有写入。本地可移植组合文件回读通过，四件共用一个家具组。其余家具与输入快照一致。
