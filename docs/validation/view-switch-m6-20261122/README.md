# 1601 首次进入 3D 与短时往返

2026-11-22。以 `a77985b3` 为基线，采用 1601 正式保存文件的只读冻结副本，活动方案 256 件家具。使用与正式程序相同的 Electron 桌面包、独立工作目录、端口及缓存，图形驱动为 ANGLE Metal Apple M6。11:00 日景，沿保存的照明与材质设置，流畅观察，GTAO、Bloom、SMAA 和光追关闭。

## 原版时间线

一次首次进入的 CPU 采样中，从点击至切换完成共 30.2 s，引擎导入约 26 ms，场景同步约 4.5 s，第一帧 WebGL 提交约 23.9 s。V8 调用栈显示，首帧主要卡在驱动返回着色程序的 uniform 信息之前。建筑构造约 2.4 s，其中约 2.2 s 用在吊顶洗墙的遮挡射线。另一次关闭采样的首开为 6.18 s，场景同步与建筑构造接近上一轮，主要差异出现在 WebGL 首帧。结果受系统着色器缓存及编译状态影响，30.2 s 是本次捕捉到的一次慢例。

短时再进入复用已有建筑与家具。每次进入仍执行一次相机过渡。退出时先同步绘制并编码 PNG，测得约 107–157 ms，再执行相机过渡及定时淡出。停留在 2D 约 20 s 后会按原显存策略释放 WebGL 上下文，下一次进入会重建资源。

## 调整

- 首次或显卡资源恢复前先绘制载入提示和转动动画，支持并行着色器编译时先提交 WebGL 材质编译。最终画质、灯光和原画布分辨率沿生产设置。
- 吊顶洗墙使用同一射线、采样和实体，先用包围盒排除光线够不到的网格，遇到实际遮挡即可结束该条光线的检查。
- 短时往返使用一次画布交叉淡入淡出，保留上次鸟瞰视角，约 150 ms 以下的往返直接显示画布。退出时留存完整尺寸的画布快照，交付读取时才编码 PNG。20 s 显存释放策略继续适用。

## M6 复测

按实际按钮点击至界面解除切换状态计算。淡出仍可在下一帧继续。比较首开时独立启动桌面配置，系统级着色器缓存未清空。
