# 精细渐进观察瓶颈定位（2026-11-17）

本机只读系统信息：Mac mini、Apple M6、12核GPU、24GB内存。没有依据型号名预先降画质，也没有将一次WebGPU结果称为芯片物理极限。继续保持1200×674／256采样、8次反弹、16次透明反弹、原材质／光源／曝光／相机及OIDN；每帧约2.07亿主采样，路径还包括反弹及直接光。

## 测量方式与限制

`test-progressive-profile-ui.cjs --desktop-only`复用同生产GLB隔离桌面基准。插桩仅通过测试路由提供，不修改生产模块或供应库：CPU记录renderSample及各dispatch调用时间，GPU复用供应库已有timestamp结果，记录内核类别与测量次数；另记录初始化、就绪、首采样与降噪阶段。轮次使用同一份GLB字节和公有相机快照，正式文件先固定复制，正式窗口不操作。

GPU占比是已采集计算内核时间的分布，未包含所有纹理复制／画布合成／浏览器与操作系统开销；时间戳异步抽样，不当作精确整芯片利用率、带宽饱和度或功耗结论。CPU累计时间是renderSample调用内计时，不能当作进程全部CPU时间。首组场景准备时间自iframe启动计算，不含之前在主编辑器取生产GLB；后续基准单列snapshotMs。单机单场景不能推断其它GPU性能或跨场景上限。

## 初步实测

证据`output/desktop-verification/progressive-profile-28MogC`，顺序64→32→128→64线程组，实际间接dispatch除数与线程组同步修改，完整采样与PNG均完成。

| 配置 | 总耗时 |
| --- | ---: |
| 原64线程组 | 47.429秒 |
| 32线程组 | 47.378秒 |
| 128线程组 | 47.873秒 |
| 重复原64 | 48.741秒 |

线程组差异小于该组重复波动，无值得发布的收益。候选平均像素差0.087–0.092/255，原版重复差0.089/255。

首个原版：解析／BVH至live-ready约1.748秒，首个有效采样消息约4.017秒，总47.429秒；1609次renderSample的CPU累计约0.553秒。采集GPU内核中MaterialKernel约29.4%、LogicKernel约29.0%、TraceRayKernel约26.1%、TraceShadowRayKernel约9.0%、介质队列筛选约6.1%；其它归约／调度很少。最后采样阶段仍稳定推进，而不是长时间卡在编译或下载。

因此当前场景的主要耗时在GPU材质／路径处理和BVH求交，不能靠继续减少CPU轮询或缩短场景准备获得倍数提升。该实现使用WebGPU计算着色器中的自定义BVH遍历，不是对原生Metal光线求交接口的调用；所测吞吐是这条实现路径的结果，不能据此宣布M6硬件已到物理上限。

## 其它候选与结论

- 更细BVH（叶大小5→2）：`progressive-profile-T4fGhd`，48.946秒对重复原版48.898秒，无收益；降噪约0.146／0.133秒。完整快照导出约0.677秒，场景153.7MB GLB、5148个源网格、20个面光和6个射灯。
- 单内核后端：`progressive-profile-Xrw7RY`，原版46.781秒。单内核中途只读读取到103次派发，其中23次GPU测量累计约36.174秒、平均约1.57秒/派发，明显回退；主动关闭隔离窗口中止，未完成256采样，不把它列为画质或完整渲染通过。测试器在关闭后的firstWindow清理分支超时，不是正式应用故障，未改其通用生命周期。
- 相同材质、3m空间单元内的不透明静态网格合并：`progressive-profile-kR0ouJ`，49.606秒→52.416秒，反而慢约5.7%。排除玻璃／透射／发光／Alpha／非均匀及镜像变换／骨骼／实例／特殊阴影对象；对象5442→2334，三角形均2244003，世界包围盒最大变化约9.86e-8m，平均像素差0.096/255。保留所有三角形并不保证BVH遍历更便宜；该轮求交内核占比上升，不能仅按对象数声称提速。
- 最新原版降噪约0.125秒、renderSample CPU约0.590秒、准备至live-ready约1.834秒。数据汇总见[results.json](results.json)。PNG已实际打开对照，未把少量像素平均差当作全场景画质认证。

所有候选都未显示稳定明显收益，生产渲染器和精细档画质设置保持上一有效版本；只交付可复现的诊断工具与记录。没有采用慢后端、固定大批次、网格合并或线程组变体。后续若要明显同画质提速，需对材质／路径内核及数据布局做实质优化，或验证其它渲染后端；这不是已完成能力，也不以芯片名称保证收益。
