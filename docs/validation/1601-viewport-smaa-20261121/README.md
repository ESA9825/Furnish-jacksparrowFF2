# 1601 第七轮 SMAA

2026-11-21。在 1601 三维选「流畅观察」，用「显示 → 边缘抗锯齿 SMAA」切换。默认关闭，选择只存入本机偏好。日景和夜景都可使用。

## 实现

- 使用 Three.js r160 的 SMAA 1x Medium 色差边缘检测、沿边搜索和邻域混合。查找纹理随本地源码提供，沿用已有的原生 MSAA 和颜色／深度目标。SMAA 放在窗口颜色输出前，GTAO、Bloom 开启时先完成各自合成。单独开启 SMAA 时额外绘制三个全屏三角形。查找纹理加载完成会触发重绘，创建中间目标失败会回退。 [Three.js r160 源码](https://github.com/mrdoob/three.js/blob/r160/examples/jsm/shaders/SMAAShader.js) · [SMAA 论文](https://www.iryoku.com/smaa/)
- 原版 0.10 色差阈值和全量邻域混合在这两段轨迹里会让少量柜门、灯带边缘更跳。试验把阈值调为 0.065，混合权重保留原值的 55%，让较低对比的边缘能参与，同时减少已经由 MSAA 做过的边缘被再次混合的幅度。
- 第六轮夜景按住鼠标时的分辨率与阴影恢复规则在两组一致，SMAA 中间图随实际画布宽高改变，查找纹理跨尺寸复用。

## 同机位、同轨迹

用正式 1601 工作区的隔离副本。两组均为 21:00 夜景，对照时显示「灯」图层、打开主灯、关闭夜灯，GTAO、Bloom 与光追关闭。两个机位位于约 1.60 m 完成面眼高。定帧输出 2840 × 1554，轨迹以夜景移动时的实际 1775 × 971 画布取样。

| 用途 | 相机 x/y/z（mm） | 目标 x/y/z（mm） | 水平视角 |
| --- | --- | --- | --- |
| 客厅窗框与灯带 | 9240 / 6460 / 1660 | 8180 / 3640 / 1840 | 84° |
| 餐边柜门缝 | 9320 / 6180 / 1660 | 8060 / 7530 / 1890 | 82° |
| 实际鼠标手势 | 9240 / 6460 / 1660 | 8180 / 3640 / 1550 | 76° |

每个视觉机位围绕固定目标水平旋转，从 −0.052 到 +0.052 rad 均匀取 29 帧。逐帧验证开关组相机坐标、目标和画布尺寸完全一致。三处并排动图按相同帧号拼接，播放速度用于放大观察。另用指针事件实测旋转、Shift 平移和白岩板茶几拖动。

窗框上沿等少数较强边缘稍平滑。窗框中部的竖边和灯带最亮的边缘变化很小，柜门窄缝仍有亚像素闪动。对三处完整裁切区计算同一像素的相邻三帧 RGB 二阶差分绝对值均值，窗框 4.257 → 4.181，柜门 1.864 → 1.864，灯带 0.882 → 0.871。该读数也包含正常画面位移。灯带亮边的小范围样本逐帧一致，柜门窄缝样本 2.985 → 3.014。SMAA 属于逐帧空间处理，细线和高频反光仍可能闪动。本轮保留为默认关闭的试验。

原始 PNG、逐帧裁切与记录保存在 `output/desktop-verification.noindex/living-furniture-YvUzDS.noindex/`。第一组定帧为 `before-0.png` 与 `after-1.png`，餐厅使用对应的 `-secondary` 图。逐帧文件按 `window`、`seam`、`strip` 和帧号命名。

## M6 实测

正式快捷方式使用的同一打包 Electron，ANGLE Metal Apple M6，依次关、开、开、关。每项手势发出 72 个指针位置，每轮茶几有 46 次有效位置更新。客厅定帧 4241 → 4244 次绘制，主场景绘制一次。

| 指标（ms） | SMAA 关闭两轮 | SMAA 开启两轮 |
| --- | --- | --- |
| 旋转绘制间隔 P50 | 19.2 / 18.3 | 19.3 / 19.8 |
| 旋转绘制间隔 P95 | 23.1 / 85.4 | 23.5 / 24.1 |
| 平移绘制间隔 P50 | 20.2 / 19.8 | 19.9 / 20.3 |
| 平移绘制间隔 P95 | 22.5 / 23.1 | 22.4 / 22.6 |
| 拖动绘制间隔 P50 | 27.9 / 27.3 | 28.0 / 28.4 |
| 有效拖动输入至 WebGL 提交 P95 | 26.6 / 26.1 | 26.6 / 26.4 |

两态都有偶发长帧。关闭的第二轮旋转尾部明显波动，数据仅反映这四轮。拖动指标包括吸附与 CPU 提交，显示器出光延迟未测。

## 验证

用 `scripts/verify/verify-living-furniture-raster.cjs` 复现。设置 `FURNISH_RASTER_SMAA=1`、`FURNISH_RASTER_PAN=1`，`FURNISH_RASTER_CAMERA`、`FURNISH_RASTER_SECOND_CAMERA`、`FURNISH_RASTER_GESTURE_CAMERA` 按上表使用 `mode: "orbit"`。基线参数 `0c60fbd3`。开关使用同一源码及相同存档副本。

两机位关闭 SMAA 的 PNG 与同次试验的离屏颜色直出逐字节一致。通过共享颜色目标、奇数尺寸、中间资源释放、独立失败回退和阴影缓存回归。桌面验证了偏好刷新、茶几撤销重做、隔离保存与生产 GLB 回读。断网 Chrome 从 `file://` 验证日景入口、SMAA 单独启用、与 GTAO 和 Bloom 同时启用，以及全部关闭后还原。源工作区哈希和活动方案 revision 相同。已清理登记的可重建资源，保留截图、逐帧日志和隔离存档。手机、窄屏、光追和全量测试未执行。
