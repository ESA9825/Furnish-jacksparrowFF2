# 1601 厨房旋转长帧与连续手势

2026-11-22。基线 `ca4d4eaa`。使用与[面光源验收](../ceiling-area-light-20261122/README.md)相同的[厨房与主卧机位](../1601-kitchen-soft-light-20261122/rooms.json)、实际 Electron 桌面包、ANGLE Metal Apple M6、原生画布 2840 × 1554。21:00，开启主灯并在隔离副本临时显示「灯」图层。流畅观察，关闭低位夜灯、GTAO、Bloom、SMAA 和光追。镜头及家具有各自固定的 72 步指针轨迹。沿上轮用主卧床测拖动。每轮重建独立桌面缓存。

## 153 ms 与追踪所得

原始记录 `room-raster-mEj4oc.noindex/results.json` 中，厨房旋转的第 61 与第 62 次绘制相隔 153.4 ms。两次 WebGL 提交分别耗时 5.6 和 5.2 ms，画布像素比均为 1.25。原记录没有这段间隔内的 Chromium 时间线或指针发送记录，所以无法确定当时的具体阻塞。追加同轨迹的旋转追踪没有重现同等长度的间隔。头几帧可以看到 WebGL 查询新程序时等待 GPU，这些已捕捉的等待发生在手势前段。

能稳定复现的是旋转接平移时的画布分辨率往返。分开录制两种手势的三轮厨房复现，平移最长绘制间隔为 55.4、63.6 和 58.1 ms，均从原生像素比 2 切回 1.25 时出现。时间线显示其中主线程在进入绘制前执行 WebGL 同步查询，GPU 进程同时在 `CALayerTreeCoordinator::ApplyBackpressure` 等待 macOS 合成器。55.4 与 63.6 ms 两次的 WebGL 等待分别约为 35.8 与 43.8 ms。追踪间隔含流式写出开销，和正常操作的手势间隔分开记录。

## 修正

夜景结束指针手势后保持低分辨率画布 180 ms。间隔较短的下一次手势可以复用同一画布缓冲区，静止后恢复全分辨率。显式截图可在已松手时立即恢复原生分辨率再取图。沿用已有画布、灯光、场景、阴影缓存和吸附。无项目字段或配置变化。

连续录制旋转接平移的一组对照中，原版平移的前两次绘制先用像素比 2，随后降到 1.25，出现一次 12.2 ms 的 WebGL 同步查询。改版平移全程为 1.25，追踪中没有该同步查询。此组连续对照的厨房平移最长间隔为 21.8 → 18.0 ms，用于验证修正机制。

追踪目录分别为 `room-raster-INg7x9.noindex/`、`room-raster-6Ylf6x.noindex/` 和 `room-raster-s69XtR.noindex/`，均位于 `output/desktop-verification.noindex/`。最后一组录制过程中正式方案另有保存。两态由同一开始时读取的 248 件家具快照启动，原始文件一致性门禁将该次标记为失败。只用该组时间线验证触发机制，正式统计另以冻结副本完成。

## 正式复测

关闭 Chromium 追踪。使用面光源验收保留的 248 件家具工作区冻结副本，避免把后来正式方案的新保存混入两态。联合使用相同镜头与每手势 72 次 Chromium 鼠标输入，厨房眼位为 x/y/z 8100 / 8800 / 1660 mm，目标 6590 / 9470 / 1610 mm，水平视角 86°。主卧拖床沿用面光源验收测试，撤销后核对复位。

按改前、改后、改后、改前四轮执行。每格为改前两轮 → 改后两轮，单位 ms。

| 动作 | 绘制间隔 P50 | 绘制间隔 P95 | 最长绘制间隔 |
| --- | --- | --- | --- |
| 厨房旋转 | 16.7／16.6 → 16.7／16.6 | 18.1／19.9 → 20.3／18.1 | 18.6／20.5 → 22.4／18.8 |
| 厨房平移 | 16.6／16.7 → 16.7／16.7 | 17.6／17.5 → 17.7／17.7 | 30.8／19.8 → 18.1／18.0 |
| 主卧拖床 | 31.7／31.5 → 33.9／32.6 | 165.2／165.1 → 163.7／166.5 | 167.4／166.0 → 166.7／167.5 |

两轮改前的厨房平移均出现一次分辨率往返，改后两轮平移全程为 1.25，之后均恢复 2840 × 1554。较长间隔之后的首次交互仍可能触发原有降分辨率。主卧每轮 45 次有效位姿变化，投影输入和吸附输出逐步相同。产生新位姿的输入从监听到 WebGL 提交 P95 为 36.5／30.9 → 33.6／31.6 ms。按 Chromium 事件时间起算则为 42.4／35.7 → 38.4／35.9 ms。表中的拖动绘制间隔也包含吸附位置维持原值的一段，输入延迟未测显示器出光。

厨房、主卧的原生夜景定帧在改前改后及面光源验收最终照片间均逐字节一致。冻结副本源文件哈希一致，正式方案由独立窗口自行保存。已按测试归属清理可再生成源码、资源和缓存，保留原图、逐帧数据、追踪及隔离副本持久存储。
