2026-11-22。基线 `e3b19e6f`。沿用上一轮[厨房推车机位、隔离起点和鼠标轨迹](../1601-kitchen-cart-drag-20261122/README.md)，主卧使用[拖床机位](../1601-kitchen-soft-light-20261122/rooms.json)。同一 248 件家具的冻结副本供两个房间和所有版本使用。实际 Furnish 桌面程序以 ANGLE Metal Apple M6 运行。流畅观察，21:00 亮灯、曝光 10，原生画布 2840 × 1554，关闭光追、低位夜灯、GTAO、Bloom、SMAA。保留原贴墙吸附、对齐参考线和移动步长。

柜内吸附先用原朝向、镜像、槽宽深、捕获范围和轴约束排除本次拖动够不到的柜体，再为可达到的柜体验证柜箱、完成面标高和实际板件。后者沿用目标居中位置和最终吸附位置的两次实体校验，保留候选顺序和编号。独立组件柜的轮廓沿原生产板件记录按当前家具值复用。实体碰撞每次按当前依赖解析板件，只有同一组已解析的板件才复用投影边界，精确截面及相交阈值继续参与判定。

## M6 前后实测

按改前、改后、改后、改前四轮运行，后半轮次交换两个房间的先后顺序。关闭 Chromium 追踪。每格列出改前两轮 → 改后两轮，时间单位为 ms。

| 指标 | 厨房推车 | 主卧床 |
| --- | --- | --- |
| 绘制间隔 P50 | 49.1 / 59.2 → 23.6 / 21.5 | 31.9 / 32.7 → 19.3 / 19.0 |
| 绘制间隔 P95 | 184.6 / 200.9 → 66.9 / 66.7 | 166.2 / 165.1 → 82.7 / 83.3 |
| 最长绘制间隔 | 288.5 / 300.1 → 110.6 / 111.5 | 167.3 / 167.1 → 84.3 / 83.8 |
| 超过 50 ms 的间隔数 | 18 / 35 → 7 / 6 | 12 / 12 → 5 / 5 |
| 单次吸附 P95 | 42.1 / 52.2 → 14.1 / 12.7 | 27.1 / 28.1 → 13.9 / 13.5 |
| 有效输入至新位姿提交 P95 | 56.3 / 72.7 → 29.6 / 27.9 | 36.5 / 37.4 → 24.3 / 23.1 |

输入延迟从 Chromium 事件时间计到对应位姿的 WebGL 提交结束。优化后，推车最长绘制空档仍跨六次输入，前五次吸附到同一位置，第六次才提交新位姿；主卧的最长空档由四次吸附位置未变和一次有效移动组成。

两房间的 72 步实际指针位置、地面投影与吸附输出分别与优化前、历史测量逐点一致。每轮推车产生 42 个有效位置，松手为 (7031.2, 8916) mm；主卧床产生 45 个，松手为 (2190, 3237) mm。撤销均复位，分辨率恢复，改前改后各房间静止夜景截图的哈希一致。

增量测试覆盖远处柜体跳过板件测试、近处实际层板阻挡、恰好接触与穿入、旋转和镜像、标高、原地替换组件配置及平面边缘吸附。实体投影继续和原精确截面算法对照。通过 18 项相关 Node 测试和隔离桌面 A/B。未运行全量、窄屏及光追验证。

本机数据和截图位于 `output/desktop-verification.noindex/room-raster-zoq7ca.noindex/`，源文件哈希一致。可再生成源码、资源与缓存按归属清理，保留方案副本、数据和截图。用 [厨房配置](../1601-kitchen-cart-drag-20261122/rooms.json)与[主卧配置](../1601-kitchen-soft-light-20261122/rooms.json)的 `master` 条目组成两房间 JSON，配置 `FURNISH_RASTER_ROUND=furniture-drag`、`FURNISH_RASTER_ROOMS`，运行 `scripts/verify/verify-living-furniture-raster.cjs`，参数为隔离方案路径和 `e3b19e6f`。

## 已有吸附开关

在 2D 的「显示 → 编辑辅助」关闭「贴墙吸附」和「对齐参考线」后，3D 平面拖动也读取这两项设置。移动步长继续生效，可设为 1 mm。2D 中拖动时按住 Option（Alt）可以临时跳过吸附和步长。现有 3D 平面拖动没有这个临时快捷键。「碰撞检查」用于显示碰撞标记。
