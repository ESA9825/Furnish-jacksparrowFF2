# 1601 二维拖动性能（2026-11-18）

## 范围与复现

正式应用快捷入口 `~/Applications/Furnish.app` 指向仓库已有的同一 Electron 45.0.0 包。专项 `scripts/verify/verify-drag-latency.cjs` 复制当前外置 1601 正式文件到 test-artifacts 登记的 `.noindex` 目录，以独立工作目录、缓存和端口启动同包；原文件前后 SHA256 一致。真实鼠标每件 60 次输入，开启墙体吸附、家具辅助线和净距，分别拖床与方块；186 件物体。测量 JS handler，不代表 GPU 帧率或所有机型的 FPS。

```sh
FURNISH_TEST_PROJECT='/absolute/path/workspace.furnish.json' node scripts/verify/verify-drag-latency.cjs
```

每轮保留 screenshots、CPU profiles、results.json 和项目副本；正常退出后清理登记的源码／vendor 副本及可再生成缓存，保留方案和证据。`FURNISH_DRAG_BASELINE` 可用源文件快照覆盖隔离工作区中的指定性能模块。

## 实测结果

| 指标（ms） | 修改前 | 修改后 |
| --- | ---: | ---: |
| 床：拖动 handler P50 / P95 / 最大 | 21.2 / 36.9 / 1070.8 | 5.1 / 6.8 / 50.4 |
| 方块：拖动 handler P50 / P95 / 最大 | 21.0 / 996.5 / 1026.6 | 4.4 / 40.8 / 49.9 |
| 床：松手 endDrag | 3370.6 | 377.1 |
| 方块：松手 endDrag | 3243.0 | 370.3 |

松手后仍实测到约 93–96 ms 的保存长任务；自动核对最大额外长任务为 65–71 ms。中间仅延后未分片的版本曾有 423 ms 自动核对长任务，因此最终采用分片而非仅把阻塞向后平移。8 ms 是检查让出的预算，不是所有几何内核的硬上限。

输入经过实际吸附，床有 3 次、方块有 18 次位置/辅助线变化；P50 含吸附锁定时的无变化输入。移动后重算净距和派生图层的帧仍可达到约 40–50 ms，不能把 P50 宣称持续 60 FPS。整个拖动采样总 handler 时间：床 4391.8 → 422.0 ms，方块 18200.3 → 871.4 ms。松手同步阻塞下降约 89%。

## 修复

- 固定 32/128 项 LRU 之外，FurnitureSolids 按活家具对象弱引用保留一份当前键的局部及世界实体，完整参数、姿态、型号规则键保持；不增加全局 LRU 容量，不简化实体。删除/恢复实例可回收，原位编辑仍按值失效。
- 厨房自动避让保留厨房快照，仅只读障碍物复用原身份，避免每次提交重新构造所有静止实体。原避让次序、结果和安装语义保持。
- 排序先做原有包络排除，再判断实际覆盖；厨房孔洞展示按所有 counter、表面设备及显式关联项的完整值失效。
- 吸附锁定在相同位置且辅助线也未变化时跳过重复重绘。Alt/Shift 和 release 的最新坐标仍沿原吸附函数；一次提交、原撤销栈保持。
- 松手沿已有 defer 保存队列，生命周期 flush 不变。自动全案核对沿原 review/spaceCheck 同一生成器分片（约 8 ms 预算，单个不可中断计算可超出），原同步 API 完整消费该生成器，阈值与顺序保持。新渲染或新手势放弃旧任务，未完成结果不发布；明确运行检查仍同步完成。

## 验证

- 同包桌面：实际拖动、fresh/cached 净距完全一致、厨房孔洞与 fresh 派生一致及表面设备移动失效、一次撤销/重做、落盘后刷新恢复，原正式文件未变。
- 真实 186 件场景对照修改前 project-core：4 组 options（全案、focusIds/maxIssues、799 mm、801 mm/不扫通道），spaceCheck 输出逐字一致。
- 核心回归：836 个 fresh 生产构造比较；140 个同时存活实例超过两级 LRU；位置/旋转/镜像/尺寸/安装/恢复；厨房自动避让、排序/实际板件、空间确认、项目往返；分片取消与只发布最新结果。
- 浏览器真实指针：drag-feature-snapping、drag-axis-lock，通过吸附中点/角点、Alt 自由位置、Shift 轴锁、整组、取消、撤销重做、旋转、390 px 与保存刷新；portable-smoke 的 HTTP/file 离线入口通过。
- 两份指针坐标夹具禁用 CSS 过渡，防止侧栏过渡时 screenCTM 在 move/down 间漂移。轴锁原代码也复现此夹具失败；核心吸附算法未为测试放宽精度。

适用语法和上述增量检查通过；未执行全仓检查、所有型号/操作组合或 GPU 性能验收。自动全案核对最终完成前显示更新中，不当作已通过。复杂几何的单次内核、同步最终提交与保存仍有成本，不宣称恒定 60 FPS 或零阻塞；具体实测见 results.json。
