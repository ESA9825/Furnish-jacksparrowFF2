# 1601 客餐厅实时光影试验

2026-11-21。试验限定 1601 的客餐厅、阳台和相接餐厨过厅，采用正常看房的眼高机位。日照来自现有保存设置。壁面和家具位置由同一份生产场景提供。桌面“流畅观察”前后均使用 WebGL。

## 显示范围

- 读取阳台主窗 `cad_window_9_3` 的生产洞口、窗台和窗顶，按已划定的三个空间预计算一张 64 × 64 窗光衰减图。窗光随离窗距离减弱，并在餐厅通向玄关和厨房处提前渐退。保留日照直射光和原有投影。窗外使用低对比度天空渐变表示背景。
- 松绿灯芯绒和樱桃木框吸收窗光的方式取决于各自的颜色、法线及粗糙度。低粗糙度、原本已有环境反射的非金属表面增加一层用实际窗洞尺寸推导的宽柔反光。白岩板的反射属于屏幕显示近似。
- 接地阴影读取家具生产网格最低处的支承件和已知地面标高。椅脚、沙发腿和茶几底部随模型位置更新，合并为一个实例网格。家具抬起、地面或家具图层隐藏时，接地阴影随之消失。旋转镜头复用位置未变的阴影数据。
- 日景由指定窗洞启用，夜间停用天空和窗光，接地效果降低。短墙剖切隐藏试验。该试验没有项目字段，预览窗光和接地网格不属于碰撞、生产导出或光追光源。

## 同机位验收

相机 `(9240, 6460, 1660) mm`，目标 `(8180, 3640, 885) mm`，水平视角 70°。相机离完成地面约 1.60 m。画布 2840 × 1554，DPR 2。保留 11:00 日景、主灯关闭、同一曝光与家具位置。机位朝客厅座位组与阳台，餐桌与餐椅位于相机背后。

补拍朝向餐厅，位置 `(9570, 5480, 1660) mm`、目标 `(8210, 7390, 1020) mm`，水平视角及灯光设定相同。已实际查看两组图。客厅窗侧墙面、沙发暗部和椅脚下的差别较明显，白岩板有宽而浅的反光过渡。餐厅距主窗更远，桌椅与柜面变化较轻，餐厅地面与玄关交界处的亮度分界已消除。

原始截图与逐帧记录保存在本机 `output/desktop-verification.noindex/living-furniture-YB5N30.noindex/`。客厅为 `before-0.png`、`after-1.png`，餐厅为 `before-0-secondary.png`、`after-1-secondary.png`。

## Apple M6 实测

Mac mini M6／24 GB，真实打包 Electron，实际 ANGLE Metal WebGL。对照 `d5c6eee8` 与本次候选，完整 248 件家具，按改前、改后、改后、改前顺序复测。相同路径发送 72 个鼠标位置。真实鼠标旋转相机及拖动茶几，四轮均有 49 个指针事件改变茶几位姿。所有时间单位为 ms。

| 指标 | 改前两轮 | 改后两轮 |
| --- | --- | --- |
| 旋转绘制帧间隔 P50 | 18.7 / 19.1 | 18.9 / 19.5 |
| 旋转绘制帧间隔 P95 | 25.3 / 24.4 | 24.7 / 25.5 |
| 拖动绘制帧间隔 P50 | 29.5 / 30.3 | 30.2 / 30.5 |
| 改变位置的指针输入到 WebGL 提交 P95 | 27.8 / 27.9 | 28.6 / 28.7 |

同一机位增加 3 次绘制调用及 70 个三角形。旋转和拖动时延接近基线。尾部偶有长帧，帧间隔也包含吸附后无需重绘的时间。输入延迟计到 WebGL 提交，显示合成时间另计。

复现使用 `scripts/verify/verify-living-furniture-raster.cjs`，基线参数 `d5c6eee8`，`FURNISH_RASTER_RUNS=before,after,after,before`，`FURNISH_RASTER_CAMERA` 和 `FURNISH_RASTER_SECOND_CAMERA` 传上述两个机位的 JSON（`mode: "orbit"`，`position` 与 `target` 为 x/y/z，`horizontalFov: 70`）。
