## 轮廓、结构和材质

1. 以标注外包为准，校正 C32 与新款的宽、深、高差异。新门使用齐平边框、独立按键板及低位底脚，取消旧款视觉上的外露竖拉手。
2. 窗采用真实框体开口、独立薄玻璃和后方有孔屏蔽网，屏风后还有分离的腔体内壁。Blender 逐层隐藏后射线依次命中玻璃、屏蔽网与内部零件。小孔是观察尺度下的模型采样。
3. 玻璃、面板、箱壳、底托和脚套分材质。冲压深度及按键布局属照片估算，细小菜单印字做外观简化。参考照片的曝光未知，棚拍机位及布光用于可比的模型观察。

[原 C32](c32.jpg)与[替换后的 PM20M2](pm20m2.jpg)采用源工程中相同的正交机位、布光和 AgX 曝光。另查看正面和另一侧，逐轮修正顶板与侧板共面、机脚外露量及窗部反光。生产装配保留原位置的 −Z 正面，以整体旋转换算坐标，图案和按键从灶前观察保持正读。

## 生产和空间复核

Blender 5.3.0（02f0899d78e3，macOS Blender.app）独立回读发布 57 个具名部件。交换 GLB 的 SHA256 为 `751d8aee20f92a553da6e1b05d2a1b1b5f4a1ad94265ddb1d0d6a8530f56e06a`。相关测试覆盖型号、来源链接、空间外包、玻璃与屏蔽网前后位置，及正式快照中的部件身份和材质。门窗透射仅由指定部件发布。验收范围为闭门模型，对开门行程、现场散热和通电状态未做实物验证。

方案中的便携 OBJ 为 856 个三角面，外包与 PBR 模型一致。该网格保留了门、窗、按键板及机脚的外形，方案文件的旧版自定义模型入口可继续打开。

1601 隔离副本用正式表单完成同样的替换，断网直接打开并从生产路径导出 57 个部件与指定门窗透射材质。随后在正式桌面表单写入紧凑 OBJ 并通过 MCP 读回，确认中心、标高、旋转、图层和其它家具一致，本次替换占用一个撤销步骤。

原位置的机身顶部到柜底灯约 443 mm、到吊柜底约 458 mm，后方到最近插座面板约 174 mm，至燃气灶一侧约 196 mm。空间核对无本件实体或通道发现，说明书另要求远离热源。
