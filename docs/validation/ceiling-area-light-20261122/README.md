# 吸顶灯和平板灯的实时面光源

2026-11-22。对照基线 `5551a05a`。流畅观察沿现有离线 Three.js r160 / WebGL 渲染。米家 L90／L60 使用矩形发光面，D40／D30／D20 使用实际灯罩范围内的椭圆面，运行时以等面积八边形积分。通用柔光吸顶灯、厨房平板灯和奥普 SE2 的照明面使用矩形。筒灯继续沿原配光角计算。

- 漫反射由接收面看到的发光面投影立体角决定，灯面视角很小时使用投影面积的远场近似。旋转、镜像、离地位置与安装尺寸沿生产构造。实时材质用等效入射方向估算高光，厨房玻璃沿已有的矩形反射通路。
- 复用 Three 的排序、透视阴影相机及缓存。运行时借用 `SpotLight` 对象传送面光参数和阴影贴图，吸顶灯与平板灯的直射亮度走面积积分分支。每张阴影图估算对应面或分区的遮挡。视锥外的掠射光采用相邻有效边缘纹素的遮挡近似，避免出现突然恢复直射光的界线。
- 厨房 300 × 600 平板灯先分配四个阴影贴图，覆盖同一灯面的四个连续分区。贴图位较少或离开厨房时用同一整片发光面，保留有限阴影样本的实时成本。反射补光和现有亮度、可见性、色温开关沿生产链。灯具几何、扣板开口、已保存方案格式不变。
- 限制为局部实时阴影近似。四区或一张中心贴图有限制，尤其是近距离复杂物体的部分遮挡。灯具的厂商实测配光仍未知。独立照明预览沿原矩形快照协议，圆灯采用等面积矩形，导出不包含实时阴影代理。

## 同机位与性能

正式快捷方式对应的 Electron 隔离副本，248 件家具，ANGLE Metal Apple M6，画布 2840 × 1554，流畅观察。对照为 21:00，主灯开启、夜灯关闭，临时显示「灯」图层，ACES 曝光 10。GTAO、Bloom、SMAA、光追关闭。复核水槽及灶台、主卧、次卧、客厅、走廊和卫生间。定帧的绘制调用、三角形和六张有效阴影图均保持一致。实际厨房平板灯用四个分区及四张贴图。厨房和主卧的关灯、日景对照均逐像素一致。

早期样片的主卧墙面出现一条明暗界线。按灯具及阴影开关逐项对照，定位到阴影视锥外直接使用无遮挡光的边缘。沿有效纹素外延后复看，墙面恢复渐变，灯槽下沿、窗帘盒和柜体的实际遮挡可辨。近镜的亮面高光仍用等效入射方向近似。
