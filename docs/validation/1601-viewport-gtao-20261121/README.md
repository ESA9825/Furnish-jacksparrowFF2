# 1601 第五轮半分辨率 GTAO

2026-11-21。打开 1601 三维并选择「流畅观察」，进入「显示 → 环境遮蔽 GTAO」切换。默认关闭，选择保存在当前设备的本地偏好。适用 1601 主三维画布和 WebGL2。离开 3D 或关闭开关时释放中间纹理。渲染目标不完整时回到原实时画布。

## 实现

- 参考项目把 GTAO 的宽、高都减半。本实现复用真实模型渲染一遍得到的颜色和深度，用深度重建法线，沿 3 个截面计算近处遮挡的角度，视空间半径 0.34 m。渲染通路改动限定到主观察画布。算法参考 [Jimenez 等人的论文](https://iryoku.com/downloads/Practical-Realtime-Strategies-for-Accurate-Indirect-Occlusion.pdf) 和 [Three.js 的 GTAO 实现](https://github.com/mrdoob/three.js/blob/r183/examples/jsm/shaders/GTAOShader.js)。
- 遮挡和深度引导去噪都用半分辨率。最终深度加权上采样保留轮廓，显示相乘的最大衰减为 14.5%。首版曾在平面上产生条带，最终加入深度像素中心对齐、共面偏置、分层采样与深度引导去噪。在 1601 两个正式眼高机位回看地砖、柜门、柜缝和椅脚。
- 按 r160 的颜色输出路径，离屏颜色目标记录已有的色调映射输出，继续使用已有抗锯齿。专门抓取一帧离屏颜色直出，用来与关闭开关的原画布比较。新增效果属于屏幕空间视觉近似，玻璃后的可见深度也可能产生局部暗边。
- 第四轮的局部暗部、曝光、灯光、材质、选取、标注及生产导出沿各自原通路，GTAO 不写入项目。进入渐进高清时停用此试验。

## M6 操作实测

Mac mini M6／24 GB，真实打包 Electron ANGLE Metal，画布 2840 × 1554（DPR 2），GTAO 与去噪 1420 × 777。关、开、开、关四轮。每个手势发出 72 个鼠标位置，分别旋转、平移和拖动白岩板茶几。新增三个全屏绘制，分别用于遮蔽、去噪、合成。场景只绘制一遍。

| 指标（ms） | 关闭两轮 | 开启两轮 |
| --- | --- | --- |
| 旋转绘制帧间隔 P50 | 13.3 / 13.1 | 16.7 / 16.1 |
| 旋转绘制帧间隔 P95 | 25.1 / 70.8 | 17.7 / 26.7 |
| 平移绘制帧间隔 P50 | 12.9 / 16.6 | 16.7 / 16.6 |
| 有效拖动输入至 WebGL 提交 P95 | 29.8 / 30.2 | 30.1 / 30.4 |

四轮各有 51 次有效茶几位置更新。固定机位由 4006 次绘制增至 4009 次，多三个全屏三角形。两版都有偶发长帧，帧时数据不证明开启可以提高帧率。显示合成延迟未计入输入到 WebGL 提交。测试进程关闭后已清理可重新生成的资源。

用 `scripts/verify/verify-living-furniture-raster.cjs` 复现，设置 `FURNISH_RASTER_GTAO=1`、`FURNISH_RASTER_PAN=1`、`FURNISH_RASTER_RUNS=before,after,after,before`，使用上表两机位和基线参数 `cb4d4f46`。
