## 正式生产复核

- 独立 Blender 重新导入并发布四份 GLB，通过尺寸、具名部件和来源哈希检查。炒锅传输限定于指定玻璃盖，改名部件和其它型号测试拒绝。
- 本地服务读取正式保存的 1601，生产 GLB 回读电饭煲、炒锅、底锅和蒸屉各 30、14、12、7 个部件，分别有 8、6、3、3 组材质。Cycles 使用 Metal GPU 实际渲染厨房。闭盖的活动状态为本次范围。
- 离线复制方案核对深抽和薄拉栏的关合、部分伸出、仅深抽全开及两层全开。生产 GLB 中的餐具位移与各承托底板一致。当前方案各记录仍沿用保存的坐标和商品字段。
- 相邻柜门与已伸出的餐具会继续产生开启范围提示。同一抽屉承托的餐具与独立障碍物分别通过针对性回归。未执行全量仓库回归或实物比对。
