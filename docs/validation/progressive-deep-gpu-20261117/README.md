# GPU路径工作集与求交深入试验（2026-11-17）

结论：20帧精细档实际GPU对照未找到明显追加提速。64MB路径池ABBA为27.192→26.160秒，约3.8%，仅作为候选保留；其它求交与调度变体没有实用优势。正式渲染器、供应库、精细档预算、材质及正式方案不变，未将小幅收益推广成全局默认。

开始时仓库干净，基线3467afb7已经包含上一轮约11%的优化和收敛资源释放。通过MCP只读确认当前正式方案为厨房B深化L形联动门，固定复制其正式工程；每组仅导出一次GLB，各轮使用同一份字节。原生打包Electron、独立`.noindex`工作目录／端口／缓存；固定1200×846、256采样、8反弹／16透明反弹、保存的日景和灯光、65°俯视机位及原OIDN。输入散列和机位见[结果](results.json)。因此不能将本轮秒数直接与上一轮不同方案的31秒相减。

总时间包含iframe初始化、解析／BVH／编译、完整采样与降噪，不含之前单列的快照及通知后的PNG采集。baseline是本轮开始时的正式渲染器，仍启用上一轮特化与FP32原位累积。下列不同组分别比较，不拼接最快帧。

| 实验组 | 原版 | 候选 |
| --- | --- | --- |
| 路径池与回收 | 27.523／26.978秒 | 64MB 26.276；256MB 30.500；固定128MB 27.283；完成像素最多重试4次27.208秒 |
| 求交布局／叶节点／栈 | 27.626／27.488秒 | 独立位置缓冲27.412；不透明阴影命中即结束叶节点27.568；栈60→实际36层27.757秒 |
| 64MB池ABBA复测 | 27.232／27.151秒 | 26.215／26.105秒 |
| 更小工作集 | 27.441／27.785秒 | 16MB 27.222；32MB 26.705；8MB 28.801秒 |

路径池大小只改变在途路径数量与溢出像素队列，不减少每像素采样。扩大工作集反而慢约11%，缩小到8MB也慢；不能按“并行更多”或“内存更小”推导性能。完成像素重试保留原子交换的唯一像素所有权，只在已达采样上限时寻找下一个像素，没有提前终止未完成像素。

独立位置缓冲逐位复制原交错属性中的四个32位分量，材质仍读取原法线／切线／UV／颜色，Alpha遮挡读取不变；仅求交位置访问改为紧凑缓冲。对照组均申请同样的存储绑定上限，该变体会额外增加一份位置数据，不作为内存优化发布。阴影叶节点变体仅在完成Alpha测试、阴影可见性和部分透明处理后，确认不透明遮挡才提前返回；相机射线继续最近命中。栈容量按供应库既有TLAS＋BLAS最坏深度公式配置，保留溢出检查；实际36层，没有靠截断遍历提速。

原版采集GPU计算内核时间约为：Logic 41%、Material 29%、TraceRay 22%、TraceShadow 7%。独立位置缓冲只将TraceRay占比变到约21.7%，总时间基本不变；缩小栈与叶节点提前结束同样未带来收益。此分布是时间戳抽样，不含所有复制／合成，不证明实际带宽或硬件利用率饱和，更不能据此认定M6达到物理极限。

全部20帧完成256采样与原生PNG采集；材质／贴图清单一致，全图平均RGBA差约0.039–0.066/255，与原版重复噪声同一量级，最大差约6–17/255。实际打开俯视候选图检查，没有观察到新增明显外观差异；未做室内玻璃近景或其他GPU认证，故没有将64MB小幅收益接入正式路径。已通过相关脚本语法、`test-progressive-view`、`test-progressive-kernels`、差异检查；未运行全量检查、正式保存恢复或其它硬件测试。

复现：先准备固定工程副本和包含mode／position／target／horizontalFov的机位JSON，然后运行：

```sh
FURNISH_TEST_PROJECT=<副本> FURNISH_PERF_CAMERA_FILE=<机位JSON> node tests/test-progressive-deep-gpu-ui.cjs --desktop-only
```

`FURNISH_DEEP_VARIANTS=baseline,positions,shadow-leaf,stack,baseline`运行求交组；`baseline,pool64,pool64,baseline`运行ABBA；`baseline,pool16,pool32,pool8,baseline`运行更小工作集。所有改写只经测试路由注入隔离iframe，正式页面没有这些实验开关。原生PNG及完整日志位于忽略的`output/desktop-verification/progressive-deep-gpu-*.noindex/`。
