# 1601 客餐厅第三轮材质与接触阴影

2026-11-21。以 `5cc663ff` 作改前基线，用 1601「方案34电气布点 · 适老与全屋控制」完整场景。两版都使用 11:00 日景、原有曝光、太阳设置、关闭的主灯和相同位置的家具。

## 实现

- 选取客餐厅、相连餐厨过厅的裸露哑光墙面，在世界坐标中叠加低对比度细颗粒和宽色调变化。第一轮试图用周期波形生成颗粒，实际眼高图出现了明显条纹，最终改为可平铺的多尺度噪声。墙砖和已有图案继续用其原材质。
- 实际保存的 800 mm 暖色地砖有显式铺贴，缝宽 2 mm。沿既有铺向、颜色和网格坐标，增加逐砖色差、釉面粗糙度变化和贴近缝线的轻微暗边。新增釉面调制避开原砖缝着色。
- 奶白色不透明柜门和抽面套用以板件坐标采样的缎光饰面响应。已有木皮、玻璃、五金与灯具沿原材质。
- 墙脚接触暗部在客餐厅及相接餐厨过厅的同一张 256 × 256 图中生成，读取实际墙体和饰面平面边界，至多 180 mm 向外衰减。架空的过梁不参与。柜底沿实际低位生产板件铺窄阴影，跟随柜体位置和显示状态，与原家具接地共用实例网格。
- 材质颗粒共用 128 × 128 纹理。所有新增效果在主三维预览中实现，使用既有 WebGL 渲染循环和阴影缓存。试验未加入全屏渲染通道、场景灯光或项目字段。
