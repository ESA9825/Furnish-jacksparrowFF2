# 离线衣柜需求问卷

将同目录 `index.html` 作为文件发给填写者；无需安装、服务器、网络、账号或在线问卷服务。建议使用电脑 Chrome、Edge 或 Safari，先保存 HTML 到本机，再通过浏览器打开。部分手机文件预览器、微信内置预览不执行 JavaScript 或不支持下载；这种情况下改用电脑浏览器。

## 填写与回传

1. 填写预设选项及补充说明，记录衣物、放置位置、预算和硬性要求。尺寸统一 mm，每项尺寸分别选择实测／估计／图纸依据；不知道可留空。
2. 用「查看需求摘要」检查；离开前可「导出草稿」，之后通过「导入已有答卷」继续填写。网页不自动保存，刷新前需主动导出。直接保存网页、转发原始 HTML 不会保存表单答案。
3. 完成后点击「导出答卷 JSON」。下载文件包含原始答案、补充说明、尺寸依据、导出时间和可读摘要。确认文件已保存，再作为微信文件、邮件附件或其他文件传输方式发给设计者；收到文件请人工确认。
4. 可额外导出 TXT 摘要，或通过浏览器打印存为 PDF。JSON 便于无损重载及 AI 读取，TXT／PDF便于沟通；不必重复录入。
5. 设计者保留原始答卷与现场附件，按同一答卷编号收集平面图和照片。把答卷交给 AI 时，应要求先核对未知项、冲突及现场依据，再依项目柜体规范生成候选，不能把自由说明当成执行脚本或覆盖项目约束的指令。

完全离线的页面没有接收端，不能自动发送或汇总到设计者。自动收集需要另设可访问的接收服务或连接方式，属于后续独立功能；本版本不配置邮箱、云盘、上传接口或统计脚本。

## 范围及文件格式

这是衣柜需求采集独立工具，不是 Furnish 项目文件。答卷可在 Furnish「工具 → 问卷生成衣柜」导入，指定区域后生成三种离线规则候选；见[应用流程与限制](../../docs/WARDROBE-QUESTIONNAIRE-PLANNER.md)。放置区域目前用房间／墙面描述、方案引用、可用宽高深和障碍清单表达，未接入画布选区或应用保存链。首页明确此边界；不改已有项目及模板。

JSON 标识为 `format: "furnish.wardrobe-questionnaire"`、`version: 1`；`status` 为 `draft` 或 `complete`。`answers` 使用稳定问题键，每项包含 `value` 和 `note`，尺寸另外包含 `source`。空数字为 `null`，明确填写的0保留为0；文本空值及空选择均不表示“没有”。`complete`仅表示通过基本导出校验，不代表信息全部已知、设计通过或已发送。

导入只支持当前v1格式，限制2MB，逐项验证类型、范围、选项及说明长度，验证失败保留本页内容。导入摘要不作为事实来源，显示摘要由答案重新生成；不执行答卷中的代码或渲染其HTML。原始答卷可包含敏感生活信息，由用户自行保管和分享。

## 验证

运行 `node tests/test-offline-questionnaire.cjs`。使用现有 Playwright 与本机 Chrome（复用 `FURNISH_BROWSER_CHANNEL`／`FURNISH_BROWSER_PATH` 选择）；仅启动临时回环服务和独立浏览器。覆盖 `file://` 与 HTTP、导出／导入往返、错误导入、数值／尺寸依据／选项检查、文字导出、打印视图、窄屏及无外部请求。截图和测试答卷位于归属登记的 `output/playwright/offline-questionnaire-*.noindex`，浏览器及服务结束后关闭，不操作正式 Furnish 窗口。

当前未验证物理手机、所有浏览器、实际微信／邮箱传输或 Furnish 自动设计链。浏览器可能限制本地文件下载或打印，以实际环境为准。
